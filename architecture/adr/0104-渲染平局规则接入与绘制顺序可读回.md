# ADR-0104 渲染平局规则接入与绘制顺序可读回

状态：已拍板 2026-09-27

## 背景

消费方第五十二批反馈（在 1.83.0 冻结提交上核对复现）：契约层的 `IRenderConventionHost.TieBreakComparer`
早已存在（先比 `sortY` 再比对象稳定 id），09 文档也把它写成排序键相同时的平局规则，但引擎适配层的
真实渲染实现从未接入这个比较器——同层且 `sortY` 逐位相等的两个可见对象，落到具体渲染管线的
`sortingOrder` 完全相同，次级并列交给引擎自带的透明排序轴兜底；而 `sortY` 逐位相等时，两个对象在
排序轴上的位置也逐位相等，引擎内部对这一步平局的处理结果不确定、可逐帧互换。消费方复现场景：近战
贴身，玩家与敌人脚下 `sortY` 逐位相同，谁盖住谁在不同帧之间闪烁互换。契约本身也没有任何方法可以
读回"这两个可见对象实际的绘制先后顺序"，问题只能靠肉眼观察画面，不能写自动化断言。

## 决策

1. **比较器语义定为规则，不再是"建议"**：`TieBreakComparer` 比较结果靠前 = 先绘制 = 位于画面更
   后方；同层且 `sortY` 逐位相等时，对象稳定 id 更小者在后（先绘制），更大者在前（后绘制）。
   09 文档与契约注释同步改措辞。
2. **契约新增两个默认接口成员**（纯加法，未重写的既有实现方行为不变）：
   - 登记方法：把一个可见对象句柄与它参与平局比较的稳定 id 关联起来。
   - 读回方法：比较两个可见对象句柄**实际落到引擎的最终绘制顺序**（离散图层、排序序号、透明排序
     轴上的最终位置，含平局偏移），不是重新调用一遍比较器算一次理论值。
3. **表现层在对象身份就绪的那一刻登记**：sprite 型 `IView` 骨架创建可见对象句柄后、拿到稳定 id 时
   调用登记方法；首次引用的资源尚未加载完成（渲染占位图）与资源已就绪两条路径共用同一个登记调用点，
   不分别接线。
4. **引擎适配层按 (图层, sortY) 精确建组，组内按比较器全序分配一个极小的排序轴方向位置偏移**：
   sortingOrder 的既有计算公式不变；只有同层且 `sortY` 逐位相等的对象才进同一组，组内按比较器排出
   全序后，各自在透明排序轴方向上叠加一个与自身在全序中位置相关、肉眼不可见量级的位置偏移，使引擎
   最终的绘制顺序与比较器全序方向一致且确定；未接入比较器（未装配）时退化为按稳定 id 升序的同一
   规则，不退化为不处理。组内成员因位置/图层变化离组时偏移归零，不留痕影响后续单独渲染的对象。
5. **生产装配点接线**：具体游戏启动时实际组装可见对象渲染器的入口，构造排序约定实现后立即把比较器
   接到渲染器，不留缺口。

## 后果

### 正面

- 同层同 `sortY` 的两个可见对象前后顺序从"引擎内部不确定、可逐帧互换"变为"按比较器全序确定"，
  根治近战贴身场景的画面闪烁。
- 新增读回能力，使"这两个对象谁在前"第一次可以写成自动化断言，不必靠肉眼观察画面。
- 纯新增契约成员与生产装配接线，未重写默认成员的既有实现方、未装配比较器的既有测试夹具行为不变。

### 负面（已知限制）

- 极小位置偏移是"确定绘制顺序"与"不引入可见位移"之间的权衡：偏移量级远小于任何美术资源的可见
  像素尺度，但严格来说仍然是对象实际位置的一次极其微小的改写，不是纯粹的渲染层面排序标记——这是
  当前引擎适配层排序机制（整数排序序号 + 透明排序轴兜底）下最小侵入的落地方式，不是引入了一套平行
  的排序通道。
- 读回方法只承诺"两个当前存活对象之间的相对顺序"，不承诺跨帧稳定（对象位置/图层本身逐帧变化是
  正常游戏行为，回读结果会随之变化）；也不覆盖"两个对象不在同一渲染器实例"的跨渲染管线比较（如
  sprite 型与后续可能出现的其它可见对象类别之间），这一情形本就不在同层同 `sortY` 平局的讨论范围内。

## 备选方案与为什么不选

- **只改文档措辞，不落地实现**：无法根治消费方复现的画面闪烁，读回能力也无从谈起，不选。
- **完全交给具体游戏在装配阶段自行处理平局**：把本该是通用排序约定一部分的能力下放给每个具体游戏
  各自实现，既不符合"技术无关、游戏无关，面向所有后续游戏"的定位，也会让不同游戏对同一份契约给出
  不一致的平局语义，不选。
- **改用更大的排序序号步进换取平局空间，而不是引入独立的位置偏移**：会压缩单层可用的 `sortY` 数值
  范围（既有数值范围限制见引擎适配层实现判断记录），且仍然需要一种手段把比较器全序映射到具体的排序
  序号增量，复杂度与本决策相当而收益更小，不选。
