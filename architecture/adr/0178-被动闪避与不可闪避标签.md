# ADR-0178 被动闪避与不可闪避标签

状态：已拍板 2026-10-10（来源：样板游戏反馈"闪避应是被动技能，主动位移键改叫翻滚"；纯加法，不声明时行为逐位不变）

## 背景

玩家把「闪避」理解为被动：被攻击时按自身闪避属性掷骰，成功则本次不受伤害、头顶飘字提示；而此前样板里叫「闪避」的是主动按键的位移动作（带无敌帧），两个概念共用一个名字。

框架核对结论（先查后补）：

- **规则已具备。** 命中表六分支里有独立的 `dodge` 分支（06 第 4.2 节），查询主体是受击者，概率取 `stat` 字段指向的属性当前值（未提供则取 `base`），掷骰用命中判定随机流，成功即终止结算并发布 `combat.attack_avoided { hitResult: Dodge }`（ADR-0098）；时间线命中与目标选择式命中走同一个结算管线。
- **缺的是接入与约定。** 起步内容包的默认命中表整张关闭、没有闪避属性、没有成长与装备来源、没有闪避飘字；"哪些攻击不可闪避"没有数据标记；引擎侧的飘字接收器只会按二维平面摆位，三维世界里头顶位置不对。

## 决策

1. **术语。** 「闪避」只指被动判定（命中表 `dodge` 分支）；原主动按键的位移技能（无敌帧 + 位移）叫「翻滚」（英文 Roll）。技能 id、动作类枚举 `ActionClass.Dodge`、取消窗口的 `{class: dodge}` 等既有标识符不改（ABI 与数据兼容），只改玩家可见的展示文案。
2. **哪些攻击可被闪避。** 结算管线里「直接伤害」的命中判定走同一张命中表：近战、远程（含投射物命中）、法术一视同仁，都先掷未命中、再掷闪避、再掷招架/偏斜/格挡。治疗不掷；周期性光环伤害（持续伤害）不掷（这两条是既有规则）。
3. **不可闪避用数据标记。** 新增框架保留技能标签 `skill.tag.unavoidable`（常量 `WellKnownSkillTags.Unavoidable`）。带此标签的技能，其全部效果在结算管线里跳过命中表的回避分支（未命中、闪避、招架、偏斜、格挡），与 `EffectContext.CanMiss = false` 同义；暴击不受影响。标签随 `EffectContext.Tags` 走完施法、投射物、光环三条路径，在 `Resolver` 一处识别，不新增 schema 字段。
4. **无敌窗口先于命中表。** 翻滚的无敌帧是命中表之前的独立步骤（手感设计 03 第 2.3 节），不受 `skill.tag.unavoidable` 影响：不可闪避的首领大招依然可以被翻滚无敌帧躲开。
5. **闪避率的来源与封顶（起步包）。** 属性 `stat.dodge_rating`（`percent` 类别）：基础点数（缺省 5 点）+ 等级成长（`prog.level_curve.growth`）+ 装备词条（物品 `stats` 或词缀 `stat_mix`），经评级换算曲线 `stat.rating.kit_dodge`（一级到十级每 100 点折 100%，即 1 点 = 1%）折成概率，再被属性自身的 `clamp.max`（0.5）封顶；命中表默认行的 `dodge` 分支 `enabled: true, stat: stat.dodge_rating`。想要旧装备随等级贬值，把曲线断点的 `y` 随等级加大；想要别的上限，改 `clamp.max`。
6. **判定式。** 命中流抽样 `< 闪避率` 即闪避；只开 `dodge` 一个分支时每次结算恰好消耗命中流一次抽样，同一种子同一属性值逐次可复现。
7. **反馈。** 起步包带 `feedback.kit_dodge_text`：`combat.attack_avoided` 且 `hit_result == "Dodge"` 时在受击者头顶飘字（文案键 `l10n.combat.kit_dodge_text`，中文「闪避」、英文 Dodge）。引擎侧的飘字接收器新增「三维锚点」构造（世界坐标锚点、上浮方向、朝向相机），颜色引用带 `dodge`/`miss` 字样时用淡青色；原二维构造行为不变。

## 后果

- 纯加法：命中表缺省关闭的游戏（未加载起步包，或自己的命中表不开 `dodge`）行为逐位不变；`skill.tag.unavoidable` 只在带该标签的技能上起作用。
- **对加载起步包的游戏的缺省影响：** 起步包默认命中表现在启用闪避：玩家与敌人都有闪避率，约 5% 起步（敌人在 2%～10%），所有直接伤害攻击都可能被闪避。不想要的游戏：在自己的数据里用 `"override": true` 覆盖 `combat.hit_table.default`（把 `dodge.enabled` 改回 false），或把 `GameOptions.HitTableConfigId` 指向自己的命中表。
- 新增公开类型 `WellKnownSkillTags`、飘字接收器的一个构造重载；既有签名不变。

## 限制（已知）

1. 本期不做「面向角度」「无法招架」之类的分类标签，只有 `unavoidable` 一个；需要时按同一约定追加保留标签。
2. 闪避率读取的是受击者当前属性值，没有「命中率抵消闪避」的第二条公式：命中属性只作用于未命中分支（ADR-0030 决策 6），闪避分支不被命中属性抵消。
3. 起步包的数值是试调起点，没有经过完整试玩校准。

## 备选方案与为什么不选

- **给 `skill.def` 加布尔字段 `can_dodge`。** 要改 schema、技能定义类与投射物状态三处，且与 `tags` 并存两套"分类"机制；保留标签零 schema 改动，投射物与光环自然继承。
- **闪避做成主动技能（带冷却的被动触发）。** 玩家已明确否决；而且无法与命中表的未命中、招架等回避分支共享优先序与统计口径。
- **在游戏层订阅伤害事件后回滚伤害。** 绕行，伤害已落地、事件已发，不可靠。
