# ADR-0157 手感演示场景 2.5D 版：固定俯角下的直立广告牌表现，复用同一导演与界面

状态：已拍板 2026-10-05（承接 [ADR-0154](0154-手感演示场景真实美术表现层导演与框架界面皮肤.md) 的演示场景，把"不做 2.5D / 3D 演示场景"里的 2.5D 做掉；表现层只读逻辑事件，不改任何逻辑与数据行为；落地 [手感设计/06](../手感设计/06_手感实验室与验收.md) 第 1 节试玩宿主）

## 背景

ADR-0154 只做了 2D 动作格的真实美术演示场景。设计者还要在 2.5D（固定俯角透视）组合里评手感：原 2.5D 试玩场景用占位精灵，画面是地面网格上的一个灰色小人，受击动作、拖影、火花、飘字和界面都看不到。适配层的精灵渲染器把精灵摆在世界平面上，俯角相机看到的是它们躺在地上的透视投影（纵向被压扁，角色像趴着），所以不能把 2D 演示场景的摆法原样搬到俯角相机下。

## 决策

1. **2.5D 演示场景仍是试玩宿主的"演示场景"选项，格子取 2.5D 动作格。** 薄场景一个，挂试玩宿主、打开演示场景字段；逻辑会话与原 2.5D 试玩场景完全相同（同一数据根加演示显示表、同一脚本、同一固定步），只换呈现。用例：同一段输入在两个场景各跑一遍，逻辑指纹逐字节相等。
2. **导演、界面、外形登记、朝向规则、单身体规则全部沿用，不另写一套 2.5D 导演。** 差别收口到一个"呈现投影"：平面模式（2D 正交俯视）与直立模式（固定俯角）。导演与界面里一切"世界点抬高多少""特效朝哪转"的换算都问投影；平面模式的公式就是 2D 原来的公式（抬高 = 世界 Y 加高度，朝向 = 绕垂直轴转），所以 2D 演示场景的画面与既有用例不变。
3. **直立 = 与相机平面平行的广告牌，脚底枢轴落在地面点上。** 角色整身渲染根、场景道具（立柱、火盆、木桶、木箱、碎石）、命中火花、挥砍拖影、尘土按它摆；地面石砖、单位阴影、冲击波环仍躺在地面（透视下是椭圆，近大远小）。**选相机平行而不是垂直地面立起**：俯角 45° 时垂直立起会把整张美术纵向压扁约三成，角色比例与 2D 演示场景不一致；相机平行的广告牌在取景焦点处与 2D 同比例，同一套美术、同一缩放，只多出透视带来的近大远小。排序仍按脚下地面点的纵坐标（沿用单位渲染器既有的深度排序），不依赖深度缓冲。
4. **广告牌朝向每帧读相机的实时姿态。** 模板预设会改相机俯角（模板取景，ADR-0150），朝向不缓存：相机推进之后，单位与道具统一转到相机姿态，换模板后下一帧自动跟上。视图收到的抬高（跳跃等）沿相机上轴抬，不沿世界纵轴。
5. **特效与界面定位。** 命中火花与拖影的位置沿相机上轴抬高；拖影在屏幕平面里的转角取"地面出手方向投到相机右轴与上轴"的角度（俯角把屏幕纵向压扁，不投影则拖影与角色朝向对不上）；飘字的出现点记为脚下地面点加头高（飘字新增头高字段，2D 仍把头高计入出现点、头高字段为 0），头顶血条同理，界面经投影换算后再由舞台相机投到屏幕。
6. **地面砖在透视下用三线性与各向异性过滤**（资源加载器已给图像资源生成 mip 链），否则远处石砖闪烁；2D 仍是双线性。
7. **两个演示场景的 F1 面板与原试玩场景是同一份面板。** 面板模型由宿主按会话生成，不因演示选项而不同；用例逐项对比演示场景与原试玩场景（2D、2.5D 各一组）的武器、体型、模板预设、场景控制靶子种类、效果通道、调参字段数与五个页面，并遍历切换每个武器、体型、预设（含全部 tpl_* 模板），断言真实美术不丢（玩家仍是英雄美术、无占位回退、无引擎侧错误），2.5D 下广告牌随模板俯角转。
8. **入口。** 菜单"手感试玩 → 打开演示场景 2.5D（真实美术）"，与 2D 演示场景入口相邻；"重建演示场景"与命令行重建入口一次生成 2D 与 2.5D 两个演示场景。

## 不做的事

- **不新增美术资源，不生成图片或视频。** 全部用 ADR-0154 已入库的英雄、小兵、精英、木桩三视图动画、特效与场景道具。
- **英雄美术只有持单手剑的一套。** 换武器、体型、模板只改手感（时间窗、顿帧、击退、取景），不改英雄外观；这是美术覆盖面的限制，不是切换功能的缺陷。
- **不做 3D 演示场景**（模型外形与广告牌是两条路线，另行立项）。
- **墙体不做成有高度的体块。** 2.5D 下竞技场的墙仍按地面平铺的深色石砖画（它们在默认取景之外），立柱是广告牌。
- **不改任何逻辑数据与基线**，数据集哈希零差异。

## 后果

### 正面

- 设计者可在 2.5D 真实画面里评手感，受击动作、拖影、火花、飘字、技能栏与手感数据同时可见，且换模板时取景与广告牌一起变。
- 2D 与 2.5D 共用一份导演与界面，新增表现只写一处；逻辑不变有可执行证据。

### 负面

- 广告牌在俯角很大的取景下会与地面产生视觉上的"贴纸感"（没有真实体积与投影）；这是 2.5D 精灵路线本身的取舍。
- 导演与舞台多了一层投影抽象，新增世界空间表现要经投影换算，不能直接写世界坐标。
