# ADR-0180 技能栏悬停详情与点击施放

状态：已拍板 2026-10-10（来源：样板游戏 A、C、D 的技能栏补齐 B 在 ADR-0175 之后做的鼠标交互；纯加法，不启用时行为逐位不变）

## 背景

ADR-0175 给了提示框内容的数据规则，样板 B 在自己的 HUD 里做了悬停详情和点击施放。样板 A、C、D 的技能栏形态不同（A 四格含按住变体、C 四格随武器风格换格、D 原本没有技能栏），而点击施放有三个共性问题：

1. **点击怎么施放。** 样板 B 直接入队“动作被触发”事件，只适用于以“按下沿”为入口的动作；A、C、D 的攻击键走输入缓冲（点按与按住分档、`hold_skill_slot`），事件入口会绕过缓冲和按住判定，行为与按键不一致。
2. **点击会穿透到世界。** C 的鼠标左键本身就是攻击键，点技能栏会同时出一次普攻；A、B、D 的世界点选也会被点击带走。
3. **动作类技能的时间怎么显示。** 轻击、重击、翻滚等带 `timeline` 的技能其 `cast_time` 是动作时长，不是读条；武器节奏动作（ADR-0176）的实际时长随主手武器攻速变，提示框写数据里的原值会和实际对不上。

## 决策

1. **提示框内容（`SkillTooltipBuilder`）增加动作类型。** 带 `timeline` 且 `cast_time > 0` 的技能类型显示“动作”、时间行叫“动作时长”（本地化键 `l10n.ui.skill_tooltip.type_action` / `action_time`，起步内容包提供中英文）。`SkillTooltipContext` 增加两个可选量 `WeaponAttackIntervalSeconds`（主手武器挥击间隔）与 `WeaponPaceReferenceSeconds`（`SkillOptions.WeaponPaceReferenceSeconds`）；技能声明了 `weapon_paced` 且两者有效时，动作时长 = 数据时长 × 间隔 ÷ 基准，与施法管线同一口径；不给则不缩放。已显式给出 `CastTime` 时以其为准（急速等由调用方折算）。
2. **三个可复用的界面控件，游戏显式启用才有效：**
   - 技能提示框视图：只排版 `SkillTooltipContent`，不认识技能或数值公式；底板与文字不接收射线；摆在被悬停格正上方并夹在父节点矩形内。
   - 技能栏交互：游戏把每格底框交给它，并提供“某格当前的提示框内容”“点击某格”两个回调；给技能栏自己挂嵌套画布与射线检测器，格子底框接收射线，其余一律不接收。
   - 界面输入桥：包装游戏当前的输入源，（a）界面发起的按键以虚拟按键事件注入输入流（按下，再隔 N 次轮询抬起），（b）鼠标按下落在界面上时吞掉这次按下与配对的抬起。
3. **点击 = 按对应热键。** 点击回调把该格对应动作的绑定键经输入桥注入：点按档取 1 次轮询间隔；按住变体格取 `ceil(hold_threshold_ms ÷ 固定步长) + 1` 次轮询。之后走与真实按键完全相同的输入映射 → 输入缓冲 → 技能绑定 → 施法管线，所以冷却、资源、读条中、目标等限制与提示和按键一致，不另开施法路径。
4. **不穿透到世界。** 世界侧不改：鼠标左键 = 攻击 / 点选的绑定由输入桥在“指针在界面上”时吞掉按下与配对抬起；先在世界按下、移到界面上抬起的操作，抬起照常送达，避免世界侧残留按下状态。
5. **起步内容包补文案。** 玩家可用的起步技能（三段轻击、重击、冲锋、翻滚、远程射击、大招、两档药水）带 `name_key` / `desc_key`，中英文各一份；说明文字不含数值（数值由提示框行按数据算出）。游戏自己的技能仍由游戏提供键。

## 后果

- 纯加法：不启用控件的游戏、不给新上下文量的调用方，提示框内容与界面行为与此前逐位一致。`SkillTooltipContent.TypeText` 在动作类技能上从“读条”变为“动作”，样板 B 的技能多为非 `timeline` 技能，不受影响。
- 样板 B 保留自己的实现，不强制迁移。
- 起步内容包的技能新增两个字段，使用起步包技能的游戏悬停时能看到名称和说明而不是技能 id 短名。

## 限制（已知）

1. 只做指针悬停与左键点击；不做键盘 / 手柄焦点导航、拖拽换位、右键菜单。
2. 提示框不显示冷却剩余；冷却中点击与按键一样被拒绝，提示由游戏自己的施法失败提示承担。
3. 按住变体的点击只能模拟“按住到阈值后松开”；需要按住更久蓄力的变体无法靠一次点击得到更大蓄力。
4. 输入桥吞鼠标按下的判断在轮询时刻取指针位置，指针在同一固定步内从界面移到世界时可能判断为界面上；固定步远短于人手移动，视为可接受。
