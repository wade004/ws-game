# ADR-0100 逐层剪辑覆盖装备层与覆盖剪辑

状态：已拍板 2026-09-26

## 背景

消费方第四十五批反馈（阻塞，3 条同源问题，一并处理）：[ADR-0072](0072-纸娃娃层逐层播放剪辑.md)
落地的"纸娃娃层逐层播放剪辑"与 [ADR-0093](0093-动画剪辑随朝向档位切换.md) 落地的"剪辑随朝向
切换"，探测范围都停留在实体挂接时点已知的信息，运行期两类常见变化没有被覆盖到：

1. **装备层不参与逐层剪辑探测**：探测范围只看 `DisplayInfo.Sprite.PaperdollLayers` 声明的身体
   默认层，装备（含新增层名、覆盖已有层名）之后新出现的层始终维持静态图，即便该装备本身带有
   对应方向/层名的逐帧美术资源也不会被用上。
2. **装备层没有自己的候选取值规则**：即便按上一条把装备层纳入探测，装备层的美术资源集是按装备
   自身引用组织的（`display.equip_visual.mesh_ref`），不是按身体默认剪辑组织的，需要一套独立的
   候选公式，不能直接照抄身体层公式。
3. **武器风格/技能覆盖剪辑不参与逐层与方向探测**：`display.weapon_style` 的 `auto_attack_anim`/
   `cast_anim_override` 解析出的剪辑标识，此前只有"整身、不分层、不随方向切换"这一条路径（
   [ADR-0093](0093-动画剪辑随朝向档位切换.md) 负面项已记录为已知限制），与默认六个状态剪辑
   享受的逐层 + 方向探测能力不对等。

三条同源于同一处设计缺口——"探测范围只看挂接时静态已知的信息，不看运行期实际发生的合成结果"，
一并处理，不分批。

## 决策

1. **逐层剪辑探测范围改为"当前实际合成出的层集合"**：不再局限于挂接时的 `PaperdollLayers`。
   表现层新增一份只读快照，记录每次纸娃娃层合成（含身体默认层与装备覆盖/新增层）之后的层名 +
   来源；引擎适配层原本"挂接时探测一次"的入口改为按这份快照的当前内容探测，并在纸娃娃层合成
   钩子（[ADR-0099](0099-纸娃娃层只在方向槽位变化时重合成.md) 已有的重合成通知出口）里比对
   "本次合成后的层名集合是否相比上一次已知集合变化"，命中（装备新增/覆盖/卸下导致层集合变化）
   即按当前层集合重新探测；纯方向变化或资源加载迟到回填导致的重合成（层名集合不变）不重复
   探测，维持既有开销。
2. **装备层候选按其挂接的资源集引用取前缀**：装备层探测候选为
   `sprite_anim.<去类别前缀的装备资源集引用>__<去类别前缀的身体或覆盖剪辑引用>__<方向裸档位名>__
   <层名>`，两级不命中再退一级去掉方向段；身体层候选不变（仍是 [ADR-0072](0072-纸娃娃层逐层播放剪辑.md)
   两级公式，不含装备段）。两类候选按同一套"逐层顺序探测、首个命中层兼作状态自身内容"机制
   （[ADR-0072](0072-纸娃娃层逐层播放剪辑.md) 决策 2）处理，不新增第二套播放机制。
3. **武器风格/技能覆盖剪辑走与默认状态相同的逐层 + 方向探测**：覆盖剪辑首次被解析出来时，按
   "覆盖剪辑自身引用"充当决策 2 公式里"身体或覆盖剪辑引用"这一段，走一遍逐层探测；至少一层
   命中时行为与默认状态完全一致（隐藏整身、按共享时间轴驱动命中层）。逐层探测两级候选都未命中
   时，退回整身候选，且整身候选同样支持
   [ADR-0093](0093-动画剪辑随朝向档位切换.md) 决策 5 的方向变体（`<覆盖剪辑引用>__<方向裸档位名>`
   → 覆盖剪辑引用本身），即"旧有的整身路径"本身也获得方向感知，不是简单退化。方向发生变化时，
   已知的覆盖剪辑集合与默认六个状态一样重新探测；装备变化时同样一并重新探测。

## 后果

### 正面

- 装备新增/覆盖的纸娃娃层与身体层享受同一套逐层动画能力，不再"装备了带动画的道具也只能显示
  静态图"。
- 武器风格/技能覆盖剪辑与默认状态剪辑在"逐层"与"随方向切换"两个维度上能力对等，不再是表现层
  的二等公民。
- 冷加载（首次引用的资源尚在异步加载）与热路径（资源已在缓存）走同一套探测出口，行为一致，
  不区分对待。
- 三项决策均为在既有探测机制上按运行期实际信息重新入参，不改变数据格式、不新增公开签名。

### 负面

- 装备变化会让该实体已经缓存过的"按方向探测结果"整体失效重新计算，比"只更新变化的这一处"更
  保守：换取的是避免"某个此前访问过的方向档位残留装备变化前的陈旧结果"这类更隐蔽的错误，装备
  变化在实际游戏节奏里不是逐帧发生的高频事件，重新计算的开销可接受。
- 覆盖剪辑逐层探测两级候选与整身方向变体候选存在异步竞态窗口（哪一个先异步返回不确定）：已按
  "谁先命中谁生效、后到达的一方发现内容已存在则不覆盖"处理，不会互相冲突，但两条路径仍可能都
  发起一次资源加载请求——多一次对已缺失资源的确认性加载尝试，不影响最终结果正确性。

## 备选方案与为什么不选

- **只做决策 3（覆盖剪辑逐层+方向探测），不做决策 1/2（装备层参与探测）**：能单独解决"武器攻击
  动作不分层"这一个问题，但装备层本身仍然是静态图——本批反馈的三条问题同源，只修一条会让另外
  两条继续以同样根因反复出现，一并处理性价比更高。
- **装备层候选复用身体层同一套两级公式（不加装备资源集引用段）**：会导致不同装备共用同一套
  资源命名空间、互相覆盖候选结果，装备美术资源本就按各自的资源集引用组织（
  [ADR-0071](0071-装备纸娃娃层随朝向换图.md) 已确立"装备层资源集引用与身体层同一位置、不同
  引用值"），候选公式理应带上这段引用，故不选。
- **覆盖剪辑没有任何逐层夹具时直接维持挂接期的整身静态占位，不再尝试整身方向变体**：实现更
  简单，但会让覆盖剪辑在"是否分层"这一点上获得了方向感知、在"完全走整身"这一点上却退回无方向
  感知的旧行为，同一决策批次内制造两套不一致的方向语义，故让整身路径也享受
  [ADR-0093](0093-动画剪辑随朝向档位切换.md) 已有的方向变体能力，不额外区分对待。
