# ADR-0115 输入缓冲与动作时间线

状态：已拍板 2026-10-01

## 背景

既有输入链路是"设备事件 → 输入映射转译 → 本 tick 意图"，只有读条结束前的法术队列窗口一处缓冲；技能只有 `cast_time` 一段动作时长，没有分相、取消窗口与连招。动作游戏的"跟手"大半来自这两处：按早了不丢、后摇里能接下一段、闪避能取消攻击。

## 决策

1. **输入缓冲**（L0 输入映射扩展）：动作类输入经每行动者的缓冲槽（槽位数、缓冲窗口、优先级、按住阈值、重复策略、方向快照由动作定义与手感档案输入组决定）；移动轴不缓冲。缓冲过期以**行动者动作时钟**计（顿帧不吃缓冲）。消费在 tick 步骤 1：无动作时接受最高优先级记录；有动作时只在该类别取消窗口打开或反应类技能时接受；管线以时间可解原因拒绝（节拍锁、公共冷却、短冷却）时记录保留重试，其余原因丢弃并发 `input.buffer_dropped`。死亡、切场景、切离散模式、读档清空。AI 与自动战斗提交到同一缓冲，不绕开取消与状态规则。
2. **宽限窗口**：泛化的"前置条件刚失效后的短暂宽限"，游戏声明条件（Expr），规则层记录条件最近为真的 tick，动作定义引用适用条件；只放宽接受，不改随后结算的几何。
3. **动作时间线**（`skill.def.timeline`）：`charge`（可选）/`startup`/`active`/`recovery` 三相之和即动作时长（与 `cast_time` 派生关系由校验保证）；时间标记（`hit`、连招窗口、按类别的取消窗口、无敌窗口、动作位移起止、投射物发射、扣费点、蓄力就绪）；`hit_policy`、`cost_at`、`cooldown_at`、`motion`、`feel_ref`。
4. **作者态权威来源** `source: data | clip`：运行期规则层永远只读 `timeline`；`clip` 为权威时由导入工具在数据构建阶段把剪辑标记抄入本块，校验器要求一致；同一事件只由一处触发（判定由规则层按 `timeline`，表现由表现层按剪辑）。
5. **取消窗口**：按目标类别独立声明；缓冲记录在其类别窗口打开时被接受即"取消进入"——关闭命中集合、停止动作位移、撤销未到标记、发 `action.cancelled` 与 `skill.cast_interrupted{CANCELLED}`（满足施法终结事件保证）；已扣资源与已起算冷却不回滚（`refund_on_cancel` 为游戏级策略）。移动轴不是打断，只在 `move` 类窗口内生效。
6. **速率重映射**：急速按同一系数等比缩放三相与判定标记，动画播放速率同系数，顿帧不缩放，窗口长度不缩放；跨帧标记按区间遍历不漏不重。
7. **连招**：`combo.next` 与窗口；窗口内攻击类记录启动下一段并递增 `comboIndex`；其它动作、待机超时、硬直、死亡重置。
8. 新增事件 `action.started/phase_changed/marker/cancelled/finished`、`input.buffer_dropped` 与只读查询 `IActionStateQuery`、`IInputBufferQuery`。

## 后果

### 正面

- "早按不丢、后摇可接、闪避可取消"由框架机制保证，游戏只填窗口数值。
- 缓冲以动作时钟计使顿帧与缓冲无冲突；一切以 tick 计使输入脚本可逐字节回放。
- 法术队列被更通用的缓冲取代，`instant` 技能沿用既有法术队列不变。

### 负面

- 动作定义与技能定义各增字段，数据校验项增多。
- "取消进入"不退资源可能与某些游戏的期望不符，故留策略项。
- 作者态 `clip` 权威要求导入工具增加一个派生数据步骤，忘记重新导入会被校验拦下而不是静默用旧值。

## 备选方案与为什么不选

- **缓冲以真实时间计**：与固定步长确定性冲突，回放不可复现；否决，真实时间戳只作诊断。
- **缓冲以模拟时钟计**：顿帧会吃掉缓冲窗口，重打击游戏里连招接不上；否决。
- **在剪辑里同时触发判定标记**：规则层读表现域违反分层；否决，改为作者态抄写。
- **取消即退资源**：可被用来免费试探；留策略项缺省不退。

## 魔兽世界的对应做法

魔兽的法术队列窗口（读条末尾可预提交下一施法）是单槽、无优先级、无取消的缓冲，本架构保留它给 `instant` 技能；魔兽没有动作分相与取消窗口，公共冷却承担节拍，本架构在关公共冷却的游戏里由三相与取消窗口承担节拍（ADR-0031 的节拍锁语义不变）。
