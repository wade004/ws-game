# ADR-0148 镜头与音画反馈的合成上限、玩家强度、脚步材质与动画表现标记

状态：已拍板 2026-10-04（落实 [手感设计/07](../手感设计/07_镜头与音画反馈.md) 第 1～4 节与 [手感设计/04](../手感设计/04_姿势与动画契约.md) 第 5 节的表现类标记；追加决定 [ADR-0113](0113-手感体系纳入框架判定型与呈现型两半拆分.md)、[ADR-0129](0129-顿帧冻结特效与粒子的可选能力接口.md)、[ADR-0146](0146-玩家手感入口与成熟度验证记录.md)）

## 背景

手感落地后对照设计复核镜头与音画反馈，发现一批"设计写了、实现没有生效"或"两边说法不一致"的缺口：

- `combat.hit_confirmed → PlayImpact(from_feel)` 只写在文档里；游戏不自己写 `PlayImpact` 规则，打击反馈包就永远不播。
- `shake_cap` 在流水线里只约束同一批命中取最大后的单次冲击，多次命中叠加的总量没有上限；实现与"震屏与冲击叠加后的上限"不符。
- 玩家强度开关只有一个按档案指定的设置名，没有全局的震屏/冲击/闪白/震动系数；规则驱动的 `shake_camera` 完全不受玩家强度影响。
- `camera_distance_attenuation` 的 `linear` 实际是"不衰减"；`camera_follow_lag_ms` 与分轴阻尼同时存在，滞后被叠两级。
- 脚步声有两个来源（动画剪辑标记与几何步幅事件），同一步可能响两次；材质没有数据来源。
- 拖尾与残影字段、`trail_start/trail_end/fx/impact` 标记没有消费方；同一剪辑里同名标记（走路剪辑的两次落脚）在关键帧索引里互相覆盖。
- 手柄震动、镜头缩放脉冲这两类常见的命中手感没有承载。
- 07 正文有若干处与实现漂移（`impulse_gain` 的单位、镜头字段的归属、缺省规则）。

## 决策

1. **框架缺省规则。** 装配根在游戏没有声明任何含 `PlayImpact` 动作的反馈规则时，自动补一条 `combat.hit_confirmed → PlayImpact(from_feel)`（规则 id `feedback.binding.framework_default_impact`）。游戏自己的规则一律优先（有任何一条就不补，不叠加成双份）；装配选项 `DefaultImpactRule` 可整体关掉；没有打击反馈包流水线时不补。

2. **`shake_cap` 是相机侧合成上限。** 相机对"仍在衰减的全部冲击与震屏"求合成幅度（方向冲击按向量合成、反向抵消，其余标量累加，线性衰减），超过上限的新冲击被缩小到用满上限、没有余量则丢弃；退化为 `shake` 的冲击受同一上限约束；0 = 相机侧不限制。流水线保持批内取最大合并与最小间隔限频不变，两层各司其职。缩放脉冲不是位移，不计入合成幅度。

3. **玩家强度是四个全局系数，在出口统一生效。** 设置键 `feel.intensity.shake` / `.impulse` / `.flash` / `.rumble`，取值 0..1、缺省 1、0 即关闭，由表现层装配持有、经窄接口读取。震屏系数作用于所有 `ICamera.shake`（含规则驱动的 `shake_camera` 与冲击退化通道），冲击系数作用于冲击与缩放脉冲，闪白系数作用于闪白出口，震动系数作用于震动出口；流水线读到保留前缀的名字时不再重复相乘。`camera_user_intensity_setting` 保留为按档案指定的命名设置项，只额外乘到该包的镜头冲击上。

4. **距离衰减与跟随滞后收口。** `camera_distance_attenuation`：`none` 为缺省（不衰减）；新增真线性 `linear:<跨度>`（跨度为身高倍数，距离 0 时系数 1、到跨度降为 0）；曲线 id 不变；旧数据的裸 `linear` 行为保持不衰减并在运行期提示迁移到 `none`（ADR-0039：不静默改手感）。阻尼是镜头平滑的唯一权威：`camera_follow_lag_ms` 弃用，仅当分轴阻尼为 0 时作为该轴阻尼取值，不再另走 `ICamera.follow` 平滑；字段保留、数据不破坏。

5. **脚步单一来源与材质。** 单位动画剪辑声明了 `footstep` 标记 → 以标记为唯一来源，几何步幅事件对该单位不再出声；没有剪辑声明 → 退回几何步幅；脚步层档位为 0 → 两者都关。材质来自地图 `world.map` 的可选字段 `surface_materials`（与 `terrain` 同形状的区域加 `material` 标签，后声明的盖住先声明的；区域之外与没有该字段的地图为通用材质）；声音层按 `(footstep, 档位, 材质)` 选 `sfx.def` 行，该材质没有行时退回无材质的通用行。同一剪辑里同名标记各自触发（关键帧索引用"名#序号"登记，触发时去掉后缀）。

6. **动画表现标记由一个表现层消费方统一处理。** rig 把剪辑上的全部标记（与命中帧同步策略无关，序列帧与模型两条路线）转发给标记来源，消费方订阅后：`footstep`（决定 5）；`trail_start/trail_end` 在手感字段 `trail_enabled` 与 `trail_ref`（`vfx.def`）齐备时开始/停止拖尾特效，`afterimage_enabled` 同步开关残影；`fx:<id>` 在单位位置播 `vfx.def` 行；`impact` 放行以闪白变体 `flash.sync = impact_marker` 推迟的闪白（超时没有标记则照常闪）。`trail_enabled`/`afterimage_enabled`/`trail_ref` 因此从 `planned` 转为 `active`。拖尾走特效通路；残影是适配层可选能力（实现该能力的 View 留半透明副本并淡出，没有的外形静默忽略）。

7. **两个新的可选适配层能力，缺省不影响旧实现。** `ICameraZoomPunch`（`supportsCameraZoomPunch`、`zoomPunch(magnitude, decayMs)`：可视范围瞬间收窄再线性回落，多次叠加合计不超过 50%）与 `IRumble`（`supportsRumble`、`rumble(strength, durationMs)`），探测方式与 `ICameraImpulse` 相同；不支持时缩放脉冲记一条诊断并忽略、震动静默忽略。打击变体新增可选对象 `camera.zoom_punch` 与 `rumble`，反馈汇聚接口新增缺省空实现的方法（ABI 只加法）。

8. **增量字段与数据形状（均为可选、缺省与此前逐位一致，ADR-0039）。** `feedback.impact_profile` 变体：`flash.sync`（`immediate`|`impact_marker`）、`camera.zoom_punch`、`rumble{strength, duration_ms}`；`world.map`：`surface_materials`。不新增手感字段、不删除手感字段；仅 `trail_enabled`/`afterimage_enabled`/`trail_ref` 的落地状态改为 `active`。

9. **验收。** 实验室新增脚本 `feel_av_feedback`（独立数据根里的 `lab_av` 打击包与 `linear:6` 预设；原有脚本与基线不变），记录缩放脉冲与震动时间线；引擎端运行期测试验收缩放脉冲、震动马达输出、闪白系数、残影与重复关键帧，期望值由规则算出。

## 后果

### 正面

- 游戏只写数据（档案、打击包、地图材质、剪辑标记）就有完整的音画反馈，不必为"默认应该有的命中反馈"自己写规则。
- 震屏总量有真正的上限，不会因连击叠加把画面顶飞；玩家有统一的光敏与强度开关，规则驱动的震屏也受控。
- 脚步声不再重复，材质有数据来源；拖尾、残影、特效挂点、闪白对齐都由剪辑上的标记驱动，与动画同步。
- 距离衰减的 `linear` 不再名不副实；滞后只有一级。

### 代价与限制

- 打开缺省规则后，原先"不写规则就没有命中反馈"的游戏会多出命中反馈（可用装配选项关闭）；已有自己 `PlayImpact` 规则的游戏不受影响。
- 旧数据的裸 `linear` 需要作者手工迁移（`none` 保持原行为、`linear:<跨度>` 才衰减），框架只提示不改。
- 残影目前只有序列帧外形实现；模型外形静默忽略（没有可复用的半透明副本机制）。
- 缩放脉冲的可视半高收窄在透视投影下通过相机距离实现，只在适配层声明支持时生效。
- 脚步材质只按地图区域标签区分，不随单位脚下的实时地形或装备变化。
