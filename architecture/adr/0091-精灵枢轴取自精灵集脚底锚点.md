# ADR-0091 精灵枢轴取自精灵集脚底锚点

状态：已拍板 2026-09-26

## 背景

消费方反馈第三十七批（`<game>` 接入方，基于 v1.73.0 冻结发布提交核实，阻塞）：两个画布尺寸/像素
密度不同的角色摆在同一逻辑坐标时，精灵图中心对齐、脚底相差约 0.82 世界单位，无法在地面正确站立。
落地期核实结论：已落地引擎适配层实现里，构造精灵集下的图像类资源时，精灵枢轴固定写死为几何中心
（画布比例坐标 0.5, 0.5），与 [ADR-0081](0081-精灵集自带像素密度在运行期生效.md) 已接入的像素
密度声明无关——像素密度只解决"图有多大"，枢轴解决"以图内哪一点对齐逻辑坐标"，本次反馈指向的正是
从未接入的后者。

精灵集自带的 `anchors.json` 本就为每个方向档位声明了一个 `root` 锚点（像素坐标，原点左上），语义
即"脚底站立点"，但运行期此前从未读取它来设置枢轴，全部图像统一按几何中心处理。

## 决策

1. **枢轴取自精灵集自己声明的脚底锚点**：解码属于某精灵集的图像类资源时，枢轴 =
   `(root 像素 X / 实际解码纹理宽度, 1 - root 像素 Y / 实际解码纹理高度)`——宽高取实际解码出的
   纹理尺寸，不取 `anchors.json` 声明的画布；两者一致时结果等价，不一致时以实际纹理为准并记一条
   诊断。仓库内并存的两种 `anchors.json` 顶层结构（见 ADR-0081"已知不一致/待办"，本次仍未收敛）
   均需支持解析。
2. **方向解析**：资源标识携带方向档位信息就用该方向声明的锚点；不带方向（精灵集本身当单张图像
   使用的既有简化）时，若该集全部方向的 `root` 一致直接用（结果与选哪个方向无关）；不一致则取该
   集声明的"首个方向档位"并记一条诊断（属于信息不完整场景下的确定性兜底，不是缺陷）。
3. **回退层级同 ADR-0081 惯例**：不属于任何精灵集、`anchors.json` 不存在/解析失败/该方向无
   `root`/`root` 超出实际纹理范围——一律回退此前固定写死的几何中心，回退路径与改动前逐字节一致，
   不影响任何未声明该字段的既有精灵集；越界记一条诊断，其余分支静默（沿用 ADR-0081 决策 1 的既有
   静默层级，不新增用户可见的失败）。
4. **复用同一份解析结果，不新增第二次磁盘读取**：与 ADR-0081 已接入的像素密度声明共用同一次
   `anchors.json` 读取与缓存，"每精灵集只读一次"这条既有诊断计数器语义不变。
5. **范围**：只影响精灵集静态图像与精灵集内的逐帧动画（本质是同一批图像资源按帧切换，共用同一条
   解码路径）。不影响：特效序列帧图集（按打包图集播放，不组织成"精灵集"、不适用"脚底对齐"语义）、
   图标、纸娃娃单文件覆盖层（扁平单文件，无伴生 `anchors.json`）、界面皮肤素材（运行期临时生成的
   占位纹理，非精灵集资产）、地图分层图（按世界矩形整体拉伸摆放，不适用单点枢轴语义）。
6. **不改排序与地图契约**：渲染排序公式仍由逻辑坐标本身决定，枢轴对齐脚底后语义自然一致，不需要
   联动改动；`display.map` 的缩放/排序偏移字段契约不变；不给任何既有公开接口新增参数。
7. **两种 `anchors.json` 顶层结构仍未收敛**：延续 ADR-0081"已知不一致/待办"——本次两种结构都已
   支持读取脚底锚点，收敛为一种仍是更大的独立决策，留待设计层后续单开任务裁决。

## 后果

### 正面

- 精灵集自带的脚底锚点第一次在运行期真正生效，不同画布尺寸/像素密度的角色能在同一逻辑坐标正确
  对齐脚底，根治消费方反馈的错位问题。
- 复用既有解析与缓存，不增加额外磁盘 IO。

### 负面（行为变更，需在发布说明标注）

- 全部已声明 `root` 的精灵集——覆盖面很广，两种生成工具在未显式指定锚点时都会给一个默认的脚底
  锚点而不是几何中心——实体在画面上会整体相对此前上移（逻辑坐标此前对齐图中心，现在对齐脚底）。
  已落地的场景摆放数据无需改动（逻辑坐标语义不变，只是视觉呈现更准确），但美术侧若曾按"图中心=
  站立点"的经验核对过效果，需要用新枢轴重新核对一次。

## 备选方案与为什么不选

- **只解决消费方举例的两个角色个案（如手工给这两个精灵集加偏移）**：治标不治本，任何后续新增
  精灵集只要脚底锚点不在图正中心就会复现同一问题；枢轴从资产自身声明推导，才是唯一能覆盖全部
  现有与未来精灵集的做法。
- **在 `display.map` 上加一个逐条目枢轴偏移字段**：与 ADR-0081"备选方案"驳回"逐条目尺度字段"
  同一理由——枢轴是资产自身属性，不应由消费实体的展示配置重复表达一次，两处都能表达迟早会互相
  打架。
