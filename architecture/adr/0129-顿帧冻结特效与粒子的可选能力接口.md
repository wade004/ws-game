# ADR-0129 顿帧冻结特效与粒子的可选能力接口

状态：已拍板 2026-10-02（对 [ADR-0117](0117-局部顿帧作为判定型手感.md) 的追加决定：顿帧在表现侧的冻结面从"角色渲染体"扩到"特效与粒子"；不改 ADR-0117 已有结论）

## 背景

ADR-0117 把局部顿帧归为判定型手感：判定侧只冻结攻击方与受击方的动作时钟，并发出 `feel.hitstop_started{unitIds}` 与 `feel.hitstop_ended`。表现侧收到名单后冻结这些单位的动画时间轴（[手感设计/07](../手感设计/07_镜头与音画反馈.md) 第 5 节）。首批落地只覆盖了角色渲染体：渲染体的可选能力接口 `IPresentationFreezable` 管渲染体自己持有的时间轴，粒子与特效不在里面，于是顿帧期间角色冻住了、挂在角色身上的拖尾与光环仍在播，观感是"人停了、特效没停"。

要补上这一面，有三件事需要拍板：

1. 冻结粒子与特效需要引擎侧的暂停原语，而渲染契约（`IRenderer2D`、特效播放器 `IVfxPlayer`）是必需接口，消费方有自写实现；直接给它们加成员会让所有自写实现必须改代码。
2. 一个特效"属于哪个单位"没有现成字段：特效表里没有"随谁冻结"的声明，而命中闪光这类特效不应该冻（冻住一个刚出现的命中闪光等于吞掉打击反馈）。
3. 冻结是状态而不是一次性动作：特效可能在冻结期间才开始播放，或资源正在异步加载、冻结中途才加载完成，只在顿帧开始那一刻暂停"当前存在的特效"会漏掉它们。

## 决策

1. **冻结能力一律做成可选能力接口，不改必需接口**。新增两个接口，探测写法是"实现方是否同时实现该接口"，探测不到视为"该实现不响应顿帧"，不抛异常，行为与改动前一致：

   ```
   interface IVfxFreezable {                    // 特效播放器的可选能力（框架自带的特效播放器实现它）
     setOwnerFrozen(ownerEntityId: Id, frozen: Bool)   // 暂停/恢复宿主单位名下的全部特效实例；幂等
     isOwnerFrozen(ownerEntityId: Id): Bool
   }
   interface IParticleFreezer {                 // 引擎适配层的二维渲染实现可选实现的粒子暂停原语
     setParticlePaused(handle: ParticleHandle, paused: Bool)   // 幂等；句柄已停止/不存在时静默忽略
   }
   ```

   与渲染体的 `IPresentationFreezable`（冻结渲染体自己的动画与程序动画原语）并列，是同一思路的三个落点：渲染体、特效播放器、粒子实例；谁持有时间轴，谁实现对应的可选接口。引擎适配层没有粒子暂停能力时，粒子既不暂停也不冻结存活时长（没停住就不能让它永不过期），顿帧对粒子不生效。
2. **"谁是冻结宿主"的判据：特效是否以实体为宿主挂接**。以锚点或挂点挂接到某实体的特效（挂接信息里带实体 id）属于该实体，随它冻结；以世界坐标、接触点、屏幕位置播放的特效没有宿主单位，永不随顿帧暂停。因此命中闪光天然不冻，拖尾、光环、灼烧这类挂在单位身上的持续特效随单位冻结。**是否冻结由特效怎么挂接决定，不在特效表里新增逐条声明字段**。
3. **整层开关仍归反馈包**：是否冻结粒子由反馈包的 `freeze_layers.particles` 决定（缺省假，粒子照常推进，行为与改动前一致）；装配根只在它为真时才对特效播放器调用冻结，解冻恒调用（幂等）。冻结名单取自 `feel.hitstop_started` 的单位集合，同一冻结区间内的延长只累加冻结，不因后到的反馈包把层开关写成假而提前恢复，直到 `feel.hitstop_ended` 统一解冻。
4. **冻结是状态，不是快照**：冻结标记挂在宿主单位上，不挂在特效实例上。冻结期间新播放的该单位特效、以及资源冷加载排队后在冻结期间补发的特效，登记宿主时按当前冻结状态从暂停起播；热路径与冷加载补发走同一个登记出口，不另写一套。同一单位重复冻结或解冻幂等，不计数。
5. **存活时长随暂停停住**：被暂停实例的剩余存活时间同时停住，解冻后从冻结点继续；否则冻结中途到期被回收，"结束恢复"恢复的是一个已经消失的特效。
6. **同一变更里一并修正的缺陷（记录在此，不另立决定）**：顿帧的层声明（`freeze_layers`）此前只在"与顿帧同一批出批的命中"里查找，而 `feel.hitstop_started` 在 tick 末排队发出，到达时命中自己的打击计划通常已在前一次出批里下发，层声明在生产链路里从不生效。修法是反馈流水线保留最近几次出批的命中，按原相关性规则取并集；保留有限代数、更老的丢弃，避免把很久以前的反馈包套到无关的顿帧上。没声明层的反馈包（含框架全部缺省数据）行为不变。

## 后果

### 正面

- 顿帧期间"人冻住、特效不冻"的割裂消失，且全部是加法：必需接口不变，自写实现不必改，旧适配层静默跳过。
- 冻结范围由"挂接方式 + 反馈包层开关"两处既有声明决定，数据侧没有新字段、没有新的登记表。
- 状态型语义让冷加载与冻结期间新播放的特效与热路径同一出口，不会出现"首次引用才加载的特效顿帧时漏冻"这类只在冷路径出现的缺陷。

### 负面

- 想让某个挂在单位身上的特效在顿帧里照常播放（例如角色身上的持续闪光），只能改它的挂接方式（改成世界挂接），或在整层上关掉 `freeze_layers.particles`；做不到逐特效例外。设计粒度停在反馈包层面，认为足够。
- 暂停原语依赖引擎适配层实现；没有实现的适配层上，粒子不冻结，行为与改动前相同，但游戏需要自己确认目标引擎适配层带了该能力。
- 流水线多保留最近几次出批的命中，内存开销是常数级。

## 备选方案与为什么不选

- **给特效播放器与二维渲染契约直接加暂停方法**：自写实现必须全部改，违反 ABI 只加不改的惯例；否决，用可选能力接口。
- **在特效表里逐条声明"顿帧时是否冻结"**：数据量大、与挂接方式重复表达同一件事，且反馈包层已有整层开关；否决。
- **冻结全部特效，含世界挂接的**：命中闪光会被冻在出现的那一帧，吞掉打击反馈；否决。
- **只在顿帧开始时给当时存在的特效打暂停快照**：漏掉冻结期间才播放与才加载完成的特效，冷路径与热路径行为不一致；否决，用宿主单位上的状态标记。
- **让冻结期间到期的特效照常回收**：解冻时恢复的是已消失的特效，表现上等于特效被顿帧吃掉；否决，存活时长随暂停停住。

## 魔兽世界的对应做法

无直接对应：魔兽没有局部顿帧，也就没有"特效随单位冻结"的问题。

## M4 增补（2026-10-03，手感落地 M4-G 与 M4-W3）

对上面决策 1 中"引擎适配层没有粒子暂停能力时，粒子既不暂停也不冻结存活时长"以及后果里"没有实现的适配层上，粒子不冻结"的口径做两处修订。原口径是两件事绑在一起：没有暂停原语就一并放弃冻结存活时长，理由是"没停住就不能让它永不过期"。按该口径，没有暂停原语的适配层上特效在冻结期间照样到期被回收，解冻时恢复的是一个已消失的特效，与决策 5 要避免的后果相同，而且同一份数据在有无暂停原语的适配层上的冻结行为不一致。

### G：存活时长恒停住（M4-G）

1. **`freeze_layers.particles` 为真时，被冻结单位名下特效的存活时长倒计时恒停住**，不再取决于适配层是否实现粒子暂停原语。停住的是倒计时，解冻后从冻结点继续。
2. **视觉暂停仍归适配层的可选原语**：实现了粒子暂停原语的适配层额外获得真实的画面暂停；没有实现的适配层上，已发射的粒子仍按引擎自己的时间轴继续飘，只是"到期被回收的时刻"被推迟到解冻之后。层开关为假（缺省）时一切不变，装配根不调用冻结。

### W3：通用兜底装饰器（M4-W3）

3. **二维渲染契约的装饰器**：为没有粒子暂停原语的适配层提供通用兜底。装饰器只用契约里已有的发射与停止原语，自己实现粒子暂停原语；给特效播放器的是装饰器自己分配的**虚拟句柄**，暂停再恢复会换真实句柄，虚拟句柄不变，对不认识的句柄静默忽略。包装入口对已经实现粒子暂停原语的适配层**原样返回、不叠第二层**；被包装者实现粒子位置更新的可选能力时，装饰器同样实现并透传位置更新（暂停期间只记录最新位置、恢复时按它重发），使特效播放器对"可选能力"的探测结果与不包装时一致。
4. **两种暂停方式**：宿主给出时间缩放口（暂停以 0、恢复以 1 调用，参数是被包装适配层自己的句柄）时优先使用——粒子留在画面上、停在原处，恢复后从停住的那一帧继续；没有时间缩放口时，暂停 = 停止真实粒子，恢复 = 按原特效、原参数、原混合模式在最近已知位置重新发射。
5. **层次约束**：无头桩所在程序集对表现层零依赖，不能直接实现表现层的可选接口，无头与测试组合改用装饰器的包装入口得到一个实现了暂停原语的无头渲染器；真实引擎适配层自己实现原语。

## M4 增补的后果

- 正面：顿帧期间特效的存活时长在任何适配层上都不再"冻结中途到期"；没有暂停原语的适配层通过一次包装即获得可用的暂停，不必每个适配层各写一份。
- 取舍边界：没有时间缩放口时，暂停等于画面上消失、恢复等于重发。循环类特效（拖尾、光环、灼烧：挂在单位身上的持续特效，也是冻结的主要对象）恢复后无缝接上，只是顿帧期间看不见；非循环特效恢复后从头重播（存活计时仍从冻结点继续，所以只播剩余时长）。这是契约原语集合决定的边界——纯"发射/停止"两个原语里没有"读出已播进度"，无法精确续播；要画面精确停在原处，适配层应实现粒子暂停原语，或给装饰器时间缩放口。
