# ADR-0163 样板游戏 P3 备忘清偿的契约决定

状态：已拍板 2026-10-07（来源：`docs/消费方反馈/消费方反馈-2026-10-07-样板游戏A-P3缺口.md` 的九条非阻塞备忘；全部为纯加法，既有行为在不使用新能力时不变，唯一的行为变化见决策 4）

## 背景

样板游戏在第 3 阶段为"框架还没提供"的九件事各自写了绕行（自己的输入过滤、自己监听事件后存档、自己读地图的音乐字段并加载、自己找商人、自己从原始存档槽还原新游戏……）。绕行能用，但每个游戏都要重写一遍，且部分绕行依赖框架内部时序。九条都不阻塞，按清单一次清偿；每条的复现用例与不变量用例见各模块判断记录。

## 决策

1. **界面词本地化与对话离开（备忘 1）。** 参考面板（对话、设置、商店）与物品提示框的行标签不再写死中文：取词走本地化文案表，键缺失时退回原中文默认词，所以不用起步包的游戏逐字不变；新增对话"离开"按钮与对应意图（关闭玩家当前对话会话）。

2. **背景音乐：播放器自带加载 + 地图音乐字段消费（备忘 2）。** 引擎适配层的音频实现不隐式加载资源（[ADR-0016](0016-引擎适配层契约阶段4联调补齐.md) 决策 6），所以"首次引用方负责加载"落在表现层：新增音乐播放器（资源未加载先加载、最新请求为准、同曲幂等、加载失败记诊断不重试）；地图行的 `music_ref` 字段此前只被校验，现由地图音乐宿主在场景加载完成时消费；表现层装配默认构造它，可由选项关闭（游戏自己管音乐时）。地图没有 `music_ref` 时不动当前音乐。

3. **商人动作的 `ref` 送达回调（备忘 3）。** 对话"商人"动作的 `ref`（商人表 id）经新增的带引用回调送达；旧回调保持并存（两者都设时先调旧的）。

4. **自动存档：地图切换与任务完成触发（备忘 4）。** 装配根订阅场景加载完成与任务完成/交付（只认玩家单位），按已有的自动存档策略开关决定是否记一笔待存；写盘在下一个固定步的触发评估阶段，同一步内多个触发合并成一次，写同一个自动存档槽。**行为变化：** 策略里"任务完成"开关默认已是开启（[10 存档与持久化] 第 6 节默认表），此前没有消费者所以没有效果，现在任务完成/交付会真实写自动存档槽；"地图切换"默认关闭，不变。

5. **面板热键可由输入绑定数据声明（备忘 5）。** 数据里声明名为 `input.action.ui_toggle_<面板>` 的按钮动作，就用它的当前绑定（可改键、可存设置）；没声明的面板沿用原写死键，可整体关闭；声明了动作的面板不再响应写死键。

6. **保存设置按键合并且幂等（备忘 6）。** 保存设置先读已存设置、只覆盖本次给的键；输入绑定键由输入映射的实时导出独占，调用方在额外字段里给同名键被忽略（修复：此前往返保存会遇到重复键异常）。已知限制：合并只覆盖不删除，没有经该入口删除某个已存设置键的办法。

7. **新游戏清空持久化域（备忘 7）。** 存档系统新增"把全部已登记段重置为默认态"的入口：按读档同序对每段做一次"段缺失"加载（声明了"段缺失时保持原状"的段不动），随后回调派生状态重建钩子；不读不写存档文件、不发事件；某段失败记诊断、其余继续，返回 false。接口默认成员返回 false（旧实现不受影响）。

8. **最小输入上下文栈（备忘 8）。** 输入映射新增压入/弹出输入上下文：栈顶上下文放行表之外的动作视为未激活（按钮不触发、轴为零），栈顶独占，弹出后下一层恢复；压入时仍按住的键给边沿接收端补"抬起"，弹出时仍按住的键只恢复"持有"、不补"按下"。参考界面在模态面板（对话、商店、暂停菜单、设置、存档）打开期间压入它（可由开关关闭，游戏自己管输入上下文时）。

9. **遭遇事件携带遭遇定义 id（备忘 9）。** 遭遇开始/胜利/失败/重置/单位加入五类事件新增定义 id 字段（旧构造重载保留，字段缺省为空）。

## 后果

- 样板游戏的九处绕行可以删掉，改用原生能力；其它游戏不用重写。
- 所有新增公开接口为纯加法（新重载、接口默认成员、新类型），公开面兼容探针 0 破坏。
- 决策 4 是唯一行为变化：声明了自动存档且没有关掉"任务完成"开关的游戏，任务完成时会多一次自动存档写盘。

## 限制（已知，随各模块判断记录登记）

1. 保存设置的合并只覆盖不删除，没有删除某个已存设置键的入口（决策 6）。
2. 清空持久化域尽力而为、不回滚：某段重置失败时其余段已经重置（决策 7）。
3. 输入上下文是动作级放行，不做按设备或按玩家分层；栈顶独占，不支持多层叠加放行（决策 8）。
4. 地图音乐宿主只在场景加载完成时切曲；同一地图内的剧情换曲由游戏直接用音乐播放器（决策 2）。

## 备选方案与为什么不选

- **在音频适配实现里隐式加载。** 违反 ADR-0016 决策 6（实现不得隐式加载，否则加载时机不可预测、引用计数无主）。
- **自动存档在事件处理现场直接写盘。** 事件派发中途状态不稳定（任务奖励尚未全部结算），推迟到下一个固定步的触发评估阶段并合并，写出的是一致状态。
- **输入上下文做按物理键屏蔽。** 改键后物理键与动作脱钩，按动作放行才能随绑定一起工作。
