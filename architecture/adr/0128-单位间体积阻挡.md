# ADR-0128 单位间体积阻挡

状态：已拍板 2026-10-02（对 [ADR-0116](0116-运动仲裁器与运动档案.md) 的追加决定：运动仲裁器对"位移遇到别的单位"补写规则；不改 ADR-0116 已有结论）

## 背景

ADR-0116 的运动仲裁器只对地形（墙体、不可走区域）裁决位移，位移撞到别的单位时没有规则：输入位移、动作位移、击退都会穿过木桩与敌人，扑击扑到目标身体里，冲刺落点与敌人重叠。游戏里"单位有体积、走路会被敌人挡住、闪避可以穿过敌人"是常见手感，且和既有的全局单位阻挡开关（只在终点判定、固定半径、不属于手感档案）不是一回事。这个能力必须可选：既有预设与没有声明的单位行为一字不变，否则所有缺省手感基线都要重烘。

设计文档（[手感设计/02](../手感设计/02_移动与运动仲裁.md) 第 3.5 节）已写了行为；本 ADR 把其中的取舍作为架构决定固定下来，供后续改动对照。

## 决策

1. **可选开启，开关在运动档案**：档案新增可选字段 `unit_body_radius`（身高倍数，标定后为世界单位，缺省不声明）；只有**本单位**档案声明且大于 0 才进入任何体积分支。没有声明的单位与既有预设、`LegacyEquivalent` 档案逐位不变。该能力与既有的全局单位阻挡开关独立、互不影响。
2. **成对语义**：体积是二维平面上的圆，半径取自各自的档案；两个单位**都**声明才互相阻挡（中心距不得小于半径之和），只有一方声明则双方互不影响（穿过）。
3. **连续扫掠防隧穿**：本 tick 的位移当作线段，与每个有体积的其他存活同图单位（以其此刻位置为圆心）求首次进入；命中后停在入射点之前一个到达容差处（与墙体阻挡同一约定，下一 tick 不会从圆里起步，撞停后不蠕动）。高速位移（冲刺、击退）因此不会一步跨过单位。
4. **动作位移按 `blocking` 声明处理，穿过只给闪避类**：`stop` 停下、`slide` 沿体积切向滑开（最多一次、不递归，切向那段仍过地形裁决）；`dash`/`step_back` 在档案字段 `dodge_through_units` 为真时整段穿过别的单位的体积（地形仍阻挡），`lunge`、`charge` 等其它种类**永不穿过**。理由：闪避的语义是无敌位移穿过敌人，扑击与冲向目标是追击型位移，穿过目标会让"扑到敌人面前"失去意义；用档案字段而不是硬编码，游戏仍可自己决定闪避是否穿过。其它位移种类要穿过需另增字段，不复用本字段。
5. **常规移动与追击**：`regular` 来源（输入位移、路径跟随）按 `wall_slide` 决定整体停下或沿体积切向滑一段；追击的停步距离取"声明的停步距离"与"双方半径之和加两个到达容差"的较大者，体积大于停步距离时站在体积边缘而不是撞上去。
6. **强制位移被挡即停，不推人**：`forced` 来源（击退等受控位移）被体积挡住时以"被阻挡"收场，不滑开，也不推开挡路的单位。
7. **不推开重叠单位**：起点已在别人体积内（出生重叠、穿过式冲刺的落点）时，只拦"让距离变近"的位移，允许走开；不做强制分离，也不做结果比起点更深的位移。
8. **范围边界**：死亡单位不阻挡；离散步（回合制）不受影响；路径跟随与追击不绕单位重新寻路（撞到体积即停，开 `wall_slide` 时滑一段）；单位按固定顺序处理，每个单位只看到别人**当前**的位置（先走的单位先占位）；体积半径随运动档案走，同一档案下所有单位同半径，不同半径靠体型原型或角色覆盖层给不同档案值。

## 后果

### 正面

- 单位有体积、冲刺穿人、击退被挡等手感可由数据声明，不需要游戏写代码。
- 缺省关闭，既有预设与基线零差异；不同来源的位移在同一个仲裁点上处理，没有新的位置写入点。
- 成对语义让"只让某些单位有体积"（如只对敌人有体积）可以直接用数据表达。

### 负面

- 不推开重叠单位，出生重叠要靠游戏自己避免；密集人群里先走的单位占位，行为依赖单位处理顺序。
- 路径跟随不绕单位，被体积挡住的追击会停在原地，复杂的群体避让需要游戏自己的寻路层承担。
- 位移每 tick 多一次对周边单位的扫掠查询，仅在声明了体积的单位上产生开销。

## 备选方案与为什么不选

- **挡人由全局开关统一决定**：粒度太粗，无法让动作位移按种类区分穿过与否，也无法只对部分单位声明；否决。
- **按位移种类硬编码"闪避穿过"**：游戏无法关闭穿过（例如不想让闪避无敌穿人的硬核玩法）；否决，用档案字段。
- **重叠时强制推开**：会引入额外的位置写入点与顺序依赖，与"位置只在仲裁点由一个来源决定"冲突；否决，只拦让距离变近的位移。
- **击退把挡路的单位一起推走**：会让一次击退产生连锁位移，难以确定性对账；否决，被挡即停。
