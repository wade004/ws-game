# ADR-0121 测试覆盖梳理第一批：十条行为语义拍板

状态：已拍板 2026-10-01

## 背景

2026-10-01 全仓库测试覆盖梳理（见 docs/复盘/测试覆盖梳理-2026-10-01.md 第 2.1 节）发现十处代码行为疑似缺陷，
均无用例钉住。本条一次拍板它们的预期语义；实现按"复现用例 + 不变量用例"各至少一条落地，用例期望由规则算出，不写裸数。

## 决策

1. **VFX 冷加载中可 Stop（D1）**。冷加载与热路径一致：`Spawn` 在资源未就绪时也返回可用句柄；对该句柄 `Stop` 取消排队，
   资源到达后不再补发。`CompositeFeedbackSink` 无论冷热都登记句柄。理由：AGENTS 第 0 节冷/热一致不变量，SFX 已如此。
2. **SFX 冷加载超时改为 dt 累计（D2）**。与 `VfxPlayer` 同一口径，去掉 `DateTime.UtcNow`；保留 `FirstLoadTimeoutSeconds` 语义。
   依赖墙钟的计时用例改为 dt 驱动，不删。理由：AGENTS 第 3 节确定性。
3. **SFX 层满时新来者优先级低于全部在播实例则拒绝（D3）**。优先级严格更低：不播、返回空句柄并记一条诊断；相等或更高：
   淘汰"最低优先级中最老"的实例（现行为不变）。理由：低优先级新音顶掉高优先级旧音不符合"优先级"本义。
4. **震屏 `profile_id` 语义 = 当前相机档的 shake preset id（D4）**。字段名不改（schema 破坏性变更政策，ADR-0039），
   在字段登记表描述里写明。当前档没有该 preset 时：不抛异常，记一条诊断并跳过本次震屏，后续派发不受影响。
   补 事件→规则→ShakeCamera→CameraHost→StubCamera 与 事件→Freeze→OnFreeze 两条端到端用例。
5. **ViewBinder 逐视图异常隔离（D5）**。`SyncAll`、`OnForwardableEvent`、`OnEntityDestroyed`、`OnSaveLoaded` 的每个
   逐视图回调各自 try/catch：失败记诊断、继续其余视图；`Destroy` 失败仍从绑定表移除该实体（绑定表不残留）。
   理由：11 章 §4 表现层异常不影响 tick。
6. **相机跟随目标丢失时保持最后位置（D6）**。跟随目标以"可能不存在"为契约（`IFollowTarget` 新增默认接口成员
   `TryGetPosition`，默认实现包装 `GetPosition`），`CameraHost.Update` 目标缺失时保持上一位置、每次丢失事件只记一条
   诊断（不逐帧刷）；目标重新出现则继续跟随。ABI 只新增。
7. **`ArchetypeRegistry.ApplyTo` 先全部校验再写（D7）**。职业、种族、天赋树全部解析成功后才调用任何 writer；失败无副作用。
   同一单位重复 `ApplyTo`：若仓库内无重复应用的调用方，则在写入前抛 `InvalidOperationException`；若有，则先撤销前一次
   以同 sourceId 写入的修正再应用。
8. **`InputMapHost.ImportBindings` 全量解析后再落地（D8）**。任一条非法则整批拒绝，原绑定不变。
9. **区域触发在实体销毁时补发离开事件（D9）**。`AreaTriggerHost` 订阅实体销毁（与 `Unloaded` 补发同一机制），
   发 `AreaTriggerLeftEvent(..., Despawned)` 并清 `_inside`。死亡但实体仍存在不算离开（尸体仍在区内），用例钉住这两种。
10. **`ShellHost.LoadGame` 场景路由失败显式暴露（D10）**。读档仍算成功（存档已加载），但 `LoadResult` 新增
    `SceneRouteFailed`（bool，默认 false）与 `SceneRouteError`（string?）两个只增字段，并记一条诊断；两条 catch 分支各一条用例。

## 后果

- 6、10 两条改公开签名（只新增），需跑 ABI 探针。
- 4 的字段语义写进登记表描述，不改样例数据。
