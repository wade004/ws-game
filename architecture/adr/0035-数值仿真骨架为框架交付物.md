# ADR-0035 数值仿真骨架为框架交付物：三级仿真、标准玩家生成器、场景表与锚点表、基线对比

状态：已拍板 2026-09-14

## 背景

静态校验只能判断"单件内容对不对得上曲线"，判断不了"曲线本身合不合理"与"组合起来会怎样"。数值总纲第 5 节的对账等式（自上而下的锚点秒伤与自下而上由装备、派生、技能算出的秒伤在带宽内相等）只有仿真能验。框架已具备条件：11 第 6 节集成测试用桩适配层驱动世界模拟不需要引擎，ADR-0003 保证同种子同输入同结果，10 有回放器。缺的是驱动层、报告与基线。

与 ADR-0014（导入工具与 UI 套件是框架交付物）、ADR-0018（编辑器随游戏走、框架提供交付物）同一逻辑：机制归框架，内容归游戏。

## 决策

1. **仿真骨架是框架交付物。** 目录建议 `core/sim`：无头运行器（复用桩适配层与世界模拟）、标准玩家生成器、场景加载、报告输出、基线对比。
2. **标准玩家生成器。** 输入等级与职业：装备按期望装备等级 E(L) 与期望品质经"预算反解"（ADR-0032 决策 3）生成标准装；技能按技能书该等级可学的填满；策略为智能释放优先级表（`ai.rotation` 格式）。
3. **三级仿真。** 战斗仿真（标准玩家对生物模板按指定等级出生，N 个种子，输出击杀/被杀时长、命中率、资源曲线、技能输出占比分布；越级矩阵输出胜率与时长热图）；成长仿真（以战斗仿真结果为输入，模拟标准玩家从一级到满级，掉落按种子掷骰，输出每级实际时长、装备等级轨迹、命中率、金币累积）；内容覆盖仿真（对每个技能、装备、生物模板批量跑，输出离群值列表按偏离排序）。
4. **数据表。** 新增 `sim.scenario`（场景定义：双方、等级、分档、次数、种子、对照锚点与带宽）、`sim.anchor`（锚点表：每级 HP、DPS、TTK、TTD、E、T、G、Q，见 数值总纲第 4.1 节）。两张表结构归框架，数归游戏。
5. **报告与基线。** 报告为结构化产物（不是数据表），包含每项统计量、对照锚点、偏离与级别；基线对比工具输出改动前后统计量差异。这是数值回归，与回放回归同一原理。
6. **11 新增测试类型"数值仿真"。** 运行方式：无头，固定种子，输出报告并与基线对比；是否列为提交门槛由游戏层决定。
7. **编辑器显示。** 沿 ADR-0018，编辑器在技能与装备编辑界面旁显示预算比值与装备评分，读同一套公式。

## 后果

### 正面

- 智能释放既是功能也是策略模型，仿真结果即真实玩家的下限体验，二者天然一致。
- 确定性让报告可当基线，数据改动的影响以统计量差异呈现。
- 内容覆盖仿真给了警告级校验一个评审入口，警告不再"和不存在一样"。

### 负面

- 仿真骨架是一个新的框架模块，需要维护与其他模块契约的一致性（预算反解、优先级表、掉落掷骰都要以只读方式接入）。
- 成长仿真的"标准玩家行为"是简化模型（按怪当量击杀、按占比做任务），与真实玩家路径有差异，只能验趋势不能验绝对值。

## 备选方案与为什么不选

- **仿真归游戏层各自实现**：否决——无头运行器、标准玩家生成、报告格式全是机制，每个游戏重写一遍会各不相同且无法互相借鉴；与 ADR-0014/0018 的交付物原则冲突。
- **只做静态校验不做仿真**：否决——对账等式与组合效应无法用静态校验表达。
- **用真实玩家操作录像做仿真输入**：否决——录像不可批量、不可参数化；回放回归已覆盖录像场景，仿真解决的是参数扫描。

## 魔兽世界的对应做法

暴雪内部有战斗模拟与数据挖掘工具，社区有成熟的输出模拟器（按优先级表模拟数千次战斗输出期望秒伤分布）。本 ADR 把"按优先级表模拟"作为框架交付物，并扩展到成长与内容覆盖两级；无直接的公开对应系统。
