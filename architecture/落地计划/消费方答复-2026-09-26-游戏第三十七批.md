## 修法

- 引擎适配层加载器解码**属于某精灵集**的图像（含逐帧动画的每一帧——它们本就走同一条解码路径）时，枢轴取该精灵集 `anchors.json` 对应方向的 `root`；`w/h` 取实际解码出的纹理尺寸（与画布声明不一致时以纹理为准并记 Warn）。
- 方向取资源 id 的 `__<dir>__` 段；单图精灵集无方向时：各方向 `root` 相同直接用，不同则取第一个声明方向并记 Warn。
- 两种 `anchors.json` 结构都支持（`directions.<dir>.root` 与 `<dir>.anchors.root`）；与 `pixels_per_unit` 共用同一次读盘缓存。
- 回退：不属于精灵集 / 无 anchors / 无 `root` / `root` 越界 → 仍 `(0.5, 0.5)`，与以前逐字一致（越界记 Warn）。
- **不动**：特效序列帧、地图分层图、图标、纸娃娃独立图、UI 皮肤、运行期占位贴图；排序公式与 `display.map.*` 契约不变。无公开签名变化。
