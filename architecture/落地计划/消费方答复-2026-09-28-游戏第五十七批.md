# 消费方答复：游戏接入方第五十七批已交付（2026-09-28）

## 结论

三条缺口成立两条半，已补，落在 **1.87.0**（标签 `v1.87.0`，发布提交 `1400b95c`，功能提交 `fa7b8026`，ADR-0108）。反馈 2 的"瞬时"一半你方漏检：`EffectKind.Energize`（`skill.def` 效果 `energize`，params 含 `power_type`）在 1.85.0 已存在，直接写资源池、不经战斗结算、不进战；缺的只是周期形态，已补。框架不引入姿态系统：坐下 = `<game>` 侧一个输入切换 + 一个光环，见"你方要做的"。

## 三条决策

1. **资源回复修饰器（资源池层通用能力）**：`IPowerHost` 新增默认成员 `AddRegenModifier(unitId, powerType, key, RegenModifier)` / `RemoveRegenModifier(unitId, powerType, key)`；`RegenModifier{Scope: out_of_combat|in_combat|both, Multiplier ≥ 0, Add}`；同 key 替换不叠加，注销清除。`PowerHost` 唯一读取点改为 `(定义速率 + Σ匹配 Add) × Π匹配 Multiplier`，负结果夹 0，`decay_out_of_combat` 不受影响。光环效果新增 `mod_power_regen`（params：`power_type` 必填，`multiplier` 默认 1，`add` 默认 0，`scope` 默认 `out_of_combat`），施加登记、移除/到期撤销，key 为光环实例 id，多光环自然叠加。
2. **周期资源恢复**：光环效果新增 `periodic_energize`（`power_type`、`amount` 每跳），每跳复用瞬时 `energize` 落地逻辑，不经 `Resolver`、不进战。
3. **治疗不再无条件进战（行为变更）**：`Resolver.Resolve()` 对治疗不再调用两次 `NotifyCombatEvent`；只有 `ApplyHealThreat` 确实改动了至少一个存活敌对单位的仇恨表时，才把**治疗来源**标记进战；被治疗方不因这次治疗改变进出战状态。伤害路径不变。治疗仇恨记账对象不变：仍加在被治疗者在敌方仇恨表里已有的条目上，不新建以治疗者为主体的条目——因此治疗者进战后若无人攻击它，`LeaveCombatDelay` 后按 ADR-0107 判定正常脱战。

不选的方案：框架内建姿态（姿态是 `<game>` 内容）；把 `PeriodicHeal` 目标资源开放为可配（治疗走治疗加成/暴击/仇恨链路，资源恢复不该继承）；治疗完全不进战（治疗仇恨已改动敌方仇恨表，进战标志应与之一致）。

## 已知限制

乘算系数不允许负数（"完全停止回复"用 0）；多个修饰器不区分来源，连乘连加由内容作者自行控制；决策 3 是有意的行为变更，既有用例无一依赖旧语义。

## 凭据

- 复现 ①（生产装配级）：挂 `mod_power_regen{multiplier=k, scope=out_of_combat}` 的单位不在战推进 T，增量 = `regen_out_of_combat × k × T`；修前只等于 `regen_out_of_combat × T`（红）。在战不生效、到期回落各一例。
- 复现 ②：`periodic_energize` N 跳后增量 = `N × amount`，`IsInCombat` 全程 false、无 `combat.entered`；修前增量 0（红）。
- 复现 ③：两个不在战单位间一次 `Heal`（含自我治疗）后双方 `IsInCombat` 均 false；修前双方 true（红）。对照：被治疗者已被存活敌对单位记账 → 治疗者进战，该条目按 `amount × HealThreatCoefficient` 增加，被治疗者状态不变。
- 不变量 8 条（同 key 替换 / Remove 静默 / 注销清除 / 先加后乘 / 负夹 0 / `both` 两态 / schema 拦截缺 `power_type`、`multiplier<0` / 瞬时 `energize` 不进战），新测试 24 例全绿。
- `Core.sln` 5139/5139，`validate_data.py --strict` 0 错误，abi_probe breaks=0 additions=17，零改既有期望。

## 你方要做的

升级 1.87.0。"坐下"做法：一条 `aura.def` 带两条效果 `mod_power_regen{power_type=<生命>, multiplier=k1, scope=out_of_combat}` 与 `mod_power_regen{power_type=<法力>, multiplier=k2, scope=out_of_combat}`；X 键施加/移除该光环，移动/受击时你方自行移除（外壳逻辑在 `<game>` 侧）。若要"喝水"式固定每跳回蓝，用 `periodic_energize`。重跑脱战回复检查点时同时带上 ADR-0107（同版）。
