  脚本注释、ADR 里对 `audit-<sha>-<日期>/…` 路径的引用是历史引文，不逐条订正；需要原文时按
  `git show <sha>:<路径>` 取回，其中 `<sha>` 填删除前的提交 `eb5a5e26`，例如：

