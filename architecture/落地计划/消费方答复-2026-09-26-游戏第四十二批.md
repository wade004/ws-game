# 消费方答复：游戏接入方第四十二批已交付（2026-09-26）

## 结论

阻塞解除，落在 **1.78.0**（标签 `v1.78.0`，发布提交 `a7f623b8`，功能提交 `c4df873c`）。ADR-0096。三条运行时解码路径**默认**带完整 mip 链 + 三线性过滤，可按种类关闭。

## 修法

- 地图分层图 / 精灵集静态图像 / 逐帧动画图集三条解码路径创建纹理时开 mip 链，解码后核实 `mipmapCount > 1`（个别平台/格式生成不了只记 Warn，不视为加载失败），`filterMode = Trilinear`；地图分层图额外 `anisoLevel`（默认 4）。
- 公开开关：引擎适配层加载器新增可写属性 `TextureSampling`（`TextureSamplingOptions`）：`MipChainForImages` / `MipChainForEffects` / `MipChainForMapLayers`（默认 true）、`FilterMode`（默认三线性，关 mip 时自动降双线性）、`MapLayerAnisoLevel`（1..16，默认 4）。全关时与 1.77.0 逐字节一致。
- 逐帧图集渗色：`MipChainForEffects` 开启时每帧切成独立纹理（各自带 mip）再建精灵，图集用完即销毁；枢轴/ppu 仍按 ADR-0095 规则；帧纹理随资源卸载一起销毁。你方无需给图集加帧间边距。
- 你方 HUD 小地图直接复用的地面纹理自动带 mip，不用改。

## 行为变更（请知悉）

显存上升约三分之一（mip 链固定开销 + 逐帧动画不再共享图集）；开启 `MipChainForEffects` 时首次加载多一次 CPU 像素拷贝。改 `TextureSampling` 只影响此后解码的资源，已缓存的不回溯。

## 凭据

- 复现（PlayMode，真实加载器）：静态占位图默认 `mipmapCount > 1`、`Trilinear`；48×48 两帧夹具动画每帧 `mipmapCount > 1`、`texture.width == 48`（独立纹理，非图集宽 96）、枢轴 ≈ (0.5, 0.0833)/ppu 32 不变；修复前 `mipmapCount == 1`。用例 `LoadAsync_DefaultOptions_GeneratesMipChainForImageAndEffectFrames_PreservingAdr0095Pivot`。
- 不变量：全关时 `mipmapCount == 1`、`Bilinear`、两帧共享同一纹理；地图分层图默认 `anisoLevel == 4`；卸载后帧纹理已销毁。用例 `Invariants_AllSwitchesOff_MatchesPreChangeBehavior_MapLayerAnisoDefault_UnloadDestroysFrameTextures`。
- `UnityResourceLoaderTests` 22/22、`DirectionAwareAnimClipTests` 2/2；`abi_probe` breaks=0；发布门禁见发布提交。
