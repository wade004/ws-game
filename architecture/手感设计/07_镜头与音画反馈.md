## 1. 打击反馈包（`feedback.impact_profile`）

一条记录把一次命中的全部表现打包，由 `combat.hit_confirmed` 驱动，两种结算模式共用：

```
struct ImpactProfile {
  id: Id
  variants: List<ImpactVariant>   // 按 (class, outcome) 选；缺项回落见下
}
struct ImpactVariant {
  class: light|medium|heavy|massive
  outcome: hit|crit|kill|avoided|whiff
  flash: Optional<{profile_id, target: target|source, sync: immediate|impact_marker}>   // 09 Flash 原语
  vfx: Optional<{vfx_id, attach: contact|target|source, orient: contact_normal|world_direction|none, scale_by_ratio: 曲线引用}>
  sfx: List<{layer: swing|whiff|impact|sweetener|voice|footstep, tier: 1..N}>   // 层 + 强度档，映射到 sfx 表行（第 3 节）
  camera: Optional<{impulse_gain: Number, shake_profile: Optional<Id>, decay_ms: Number, zoom_punch: Number}>
  rumble: Optional<{strength: 0..1, duration_ms: Number}>         // 手柄震动（可选能力）
  floating_text: Optional<{style_id}>                             // 09 第 6.2 节
  trail: Optional<{start: active_start|hit, end: active_end}>     // 作者意图，仅承载（第 3.3 节）
  freeze_layers: {particles: Bool, trail: Bool}                   // 顿帧期间冻结哪些层（第 5 节）；骨骼/序列帧恒冻，不用声明
  intensity: {ratio_curve: 曲线引用, crit_multiplier: Number, kill_multiplier: Number}   // 按 amountRatio/isCrit/isKill 缩放幅度类字段
}
```

- **变体选择**：按 `(class, outcome)` 取变体；`crit`/`kill` 缺项回落 `hit`；事件里的 `impactClass` 缺项回落 `medium`；`avoided`/`whiff` 不回落（回避类只播挥空/格挡类反馈，**不播成功命中的完整反馈**）。
- **幅度单位**：变体里 `camera.impulse_gain` 是**无量纲乘数**（缺省 1）；真正的"画面高度比例"幅度来自受击链手感表字段 `camera_impulse_gain`，最终幅度 = `camera_impulse_gain` × 变体乘数 × 曲线与暴击/击杀倍率 × 距离衰减（第 2 节）× 玩家强度（第 2.1 节）。`zoom_punch` 是缩放脉冲峰值（可视范围收窄的比例，缺省 0 = 不做），在 `decay_ms`（缺省 120）内回落。
- **反馈绑定动作** `PlayImpact(profileId | from_feel)`（09 第 6.1 节固定集合第八项）。`from_feel` 取受击方解析后手感表特效组的 `impact_profile_ref`，再按事件的 `impactClass`/`hitResult`/`isCrit`/`isKill` 选变体。
- **框架缺省规则**：装配根在游戏**没有声明任何含 `PlayImpact` 动作的反馈规则**时，自动补一条 `combat.hit_confirmed → PlayImpact(from_feel)`（规则 id `feedback.binding.framework_default_impact`）。游戏只要自己写了任何一条带 `PlayImpact` 的规则，缺省规则就不加，不会与游戏规则叠加成双份反馈；装配选项 `DefaultImpactRule = false` 可整体关掉缺省规则。没有手感装配（没有打击反馈包流水线）时缺省规则不存在，行为与此前一致。
- `instant` 模式仍可用 `sync: hit_frame`（ADR-0017）把反馈延到命中帧；`timeline` 模式的命中本来就在接触时刻，缺省不同步。闪白另有 `sync: impact_marker`：推迟到闪白对象当前剪辑的 `impact` 标记（第 3.3 节），超时没有标记则照常闪。
- 后仰、倒地等身体反应不由反馈包决定，而由 `reaction` 字段选姿势键（04 第 2.2 节 `hit.*`）；反馈包只叠加闪白、特效与音画。
- 慢动作不在反馈包里：击杀慢镜头由玩法层钩子对 `combat.hit_confirmed{isKill}` 发时间尺度请求（00 第 5 节）。

## 2. 镜头档案

镜头手感字段属于**手感档案**（受击链与角色层的 `camera_*` 字段，见 [05a](05a_字段登记表.md)），由手感解析得到镜头所有者（跟随目标）的档案；既有 `camera_profile` 表只承载基础镜头参数（俯角、缩放范围、边界、震屏预设），不再扩展这些字段。全部呈现型：

| 字段 | 单位 | 说明 |
|---|---|---|
| `camera_follow_lag_ms` | ms | **已弃用**：阻尼是镜头平滑的唯一权威；分轴阻尼为 0 的轴取本值作为该轴阻尼，不再另走 `ICamera.follow` 的平滑（避免两级滞后叠加，实际滞后翻倍） |
| `camera_look_ahead` | 身高倍数 | 沿速度方向的前瞻距离；`camera_look_ahead_lag_ms` 让前瞻点自身也有滞后，避免反转时甩动 |
| `camera_dead_zone_width/height` | 身高倍数 | 目标在死区内镜头不动 |
| `camera_damping_x_ms` / `camera_damping_y_ms` | ms | 分轴阻尼（一阶滞后时间常数） |
| `camera_combat_zoom_delta` / `camera_combat_zoom_blend_ms` | 倍率 / ms | 进出战斗的缩放变化与过渡 |
| `camera_impulse_gain` | 画面高度比例 | 镜头冲击基准幅度（乘反馈包变体的 `impulse_gain` 乘数） |
| `camera_impulse_min_interval_ms` | ms | 冲击合并的最小间隔（流水线侧，第 4 节） |
| `camera_shake_cap` | 画面高度比例 | **相机侧合成上限**：所有仍在衰减的冲击与震屏的合成幅度之和不超过它；0 = 相机侧不限制 |
| `camera_distance_attenuation` | 文本 | 命中点到跟随目标的距离（身高倍数）衰减：`none`（缺省）、`linear:<跨度>`、曲线 id |
| `camera_user_intensity_setting` | 设置项引用 | 玩家可调强度的命名设置项，额外乘到该包的镜头冲击上（可选） |

镜头系统（表现层，引擎无关）按档案算出目标点（前瞻、死区、阻尼），再调既有 `ICamera.follow`；冲击经可选能力 `supportsCameraImpulse` 的 `impulse(direction, magnitude, decayMs)`，不支持时退化为 `shake`（05 第 7 节降级，强度 = 画面高度比例 × 参考镜头高度）。幅度以画面比例计，随缩放自动换算，不跨投影直接复用世界距离。缩放脉冲经可选能力 `supportsCameraZoomPunch` 的 `zoomPunch(magnitude, decayMs)`：可视范围瞬间收窄 `magnitude` 再线性回落，多次脉冲按比例叠加且合计收窄不超过 50%，不支持时忽略并记一条诊断（缩放脉冲不是位移，不计入合成上限）。

**合成上限（`shake_cap`）的口径**：流水线对同一批命中取合并后的单次冲击（第 4 节，批内取最大），相机侧再对"此刻仍在衰减的全部冲击与震屏"求合成幅度——方向冲击按向量合成（反向的互相抵消）、无方向冲击与震屏幅度按标量累加，线性衰减到各自历时——新冲击会使合成超过上限时被缩小到刚好用满上限，没有余量时整个丢弃。退化为 `shake` 的冲击受同一个上限约束。上限因此约束的是多次命中叠加的总量，而不只是单次命中。

**距离衰减**：`none` 不衰减；`linear:<跨度>` 是真线性——命中点到镜头所有者的距离为 0 时系数 1，到跨度（身高倍数）时降为 0，其间线性；其它值当曲线 id（横轴身高倍数）取系数。旧数据把"不衰减"写成裸 `linear`：行为保持不衰减，运行期提示迁移到 `none`（ADR-0039，不静默改手感）。

### 2.1 玩家强度

四个全局系数写在设置文件的 `feel.intensity.shake` / `.impulse` / `.flash` / `.rumble`，取值 0..1、缺省 1、0 即关闭；在**出口**统一生效（不在规则或流水线里各乘一次）：

| 系数 | 作用的出口 |
|---|---|
| `shake` | 所有 `ICamera.shake` 调用，包括规则驱动的 `shake_camera` 与冲击退化通道 |
| `impulse` | 镜头冲击与缩放脉冲 |
| `flash` | 闪白（0 = 不闪，光敏类无障碍的主要开关） |
| `rumble` | 手柄震动强度（乘后夹到 1） |

关闭时只关对应的表现，其余反馈不受影响。`camera_user_intensity_setting` 是另一条按档案指定的命名设置项，仅额外乘到该包的镜头冲击上，与四个全局系数不重复相乘（流水线读到保留前缀的名字时不再乘）。

## 3. 音画反馈

### 3.1 音效分层与限流

- 六个手感层：`swing`（挥动）、`whiff`（挥空）、`impact`（命中）、`sweetener`（增味，低频/高频点缀）、`voice`（发声）、`footstep`（脚步）。每层若干强度档，`sfx` 表按 `(layer, tier, 可选材质)` 登记行；反馈包只引用层与档，不引用资源。
- 并发：沿 ADR-0105 的同层并发名额；反馈包层面另加 `MaxImpactsPerTick`（缺省 4，同一 tick 超出的命中只播第一批的音效，其余静默）。
- 顿帧不影响音效播放（已发声的继续）。

### 3.2 脚步

脚步声只有**一个来源**，由单位所用动画剪辑是否声明了 `footstep` 标记决定：

- 剪辑声明了 `footstep` 标记（一个走路剪辑可声明两次落脚，同名标记各自触发）→ 以标记为唯一来源，几何步幅事件（`unit.stride_completed`）对该单位不再出声；
- 没有任何剪辑声明 → 退回 `unit.stride_completed` 几何步幅；
- 脚步层档位（`sfx_footstep_tier`，角色主导）为 0 → 关闭，两个来源都不出声。

**材质**：地图 `world.map` 的可选字段 `surface_materials`（与 `terrain` 同形状的区域加 `material` 标签；后声明的盖住先声明的）给出单位脚下的材质；区域之外与没有该字段的地图为通用材质。声音层按 `(footstep, 档位, 材质)` 选 `sfx.def` 行，该材质没有行时退回无材质的通用行。

### 3.3 动画表现标记

剪辑上的时间标记经 rig 统一转发（序列帧与模型两条路线、不论命中帧同步策略），由一个表现层的标记消费方订阅：

| 标记 | 效果 |
|---|---|
| `footstep` | 第 3.2 节 |
| `trail_start` / `trail_end` | 手感字段 `trail_enabled` 且 `trail_ref`（`vfx.def` 行）齐备时，开始标记播该拖尾特效（锚点挂接的跟随持有者，世界挂接的取开始时刻的位置），结束标记停掉；`afterimage_enabled` 同步开关残影 |
| `fx:<id>` | 在单位位置播 `vfx.def` 行 `<id>`（特效挂点触发） |
| `impact` | 放行以 `flash.sync = impact_marker` 推迟的闪白 |

拖尾与残影由适配层渲染：拖尾走特效通路，残影是可选能力（实现该能力的 View 把精灵半透明副本按固定间隔留在原地并淡出，没有该能力的外形静默忽略）。拖尾与残影的三个字段（`trail_enabled`/`afterimage_enabled`/`trail_ref`）都是武器主导（取发出标记的单位当前武器的档案）；打击变体里的 `trail` 对象只是作者意图，运行期不驱动渲染。

### 3.4 手柄震动

可选能力 `IRumble`（`supportsRumble`、`rumble(strength, durationMs)`）：变体的 `rumble` 在命中批出时下发，强度乘玩家强度 `rumble` 并夹到 1；适配层不支持或没有设备时静默忽略，不报错。后到的震动与进行中的取强度较大者、时长取剩余较长者，不累加。

## 4. 群体命中的合并（表现侧）

| 对象 | 规则 |
|---|---|
| 攻击方顿帧 | 判定型已取最大并限幅（03 第 3.2 节），表现只跟随 |
| 镜头冲击 | 流水线侧：同一 tick 合并为一次，方向取幅度加权和，幅度取批内最大；`camera_impulse_min_interval_ms` 内的后续冲击丢弃。相机侧：合成幅度按 `camera_shake_cap` 截断（第 2 节） |
| 音效 | 同层并发名额 + `MaxImpactsPerTick` |
| 特效 | 每目标各自播放，`MaxVfxPerTick` 上限（缺省 0 = 不限） |
| 闪白/后仰 | 每目标各自，不合并 |
| 飘字 | 既有合并规则（09 第 6.3 节） |

每个敌人的受击、伤害仍正常结算；未参与的角色默认继续模拟与播放。

## 5. 顿帧期间的表现

收到 `feel.hitstop_started{unitIds}`：冻结这些实体的动画时间轴（序列帧/骨骼必冻）与程序动画原语时间轴；粒子与拖尾按反馈包 `freeze_layers` 决定（粒子或拖尾任一为真时，该单位的挂接特效随之冻结）；其它实体、界面、调参面板、镜头照常。`feel.hitstop_ended` 解冻并从冻结点继续。表现帧不停，因此冻结中的实体仍可被闪白（闪白参数时间轴与动画时间轴分开）。

粒子与特效的冻结规则（`freeze_layers.particles` 为真时；可选能力接口与"谁是冻结宿主"的决定见 [ADR-0129](../adr/0129-顿帧冻结特效与粒子的可选能力接口.md)）：
- **属于谁**：以某个实体为宿主挂接的特效（挂在锚点或挂点上的持续特效：拖尾、光环、灼烧）属于该实体，随它冻结；以世界坐标/接触点/屏幕位置播放的一次性特效（命中闪光、屏幕特效）没有宿主，不冻。是否随单位冻结因此由特效怎么挂接决定，不在特效表里逐条声明。
- **状态而非快照**：冻结标记挂在单位上；冻结期间才播放的该单位特效（含资源尚在加载、加载完成后才真正播出的）同样从暂停状态起播；同一单位重复冻结/解冻幂等，不计数。
- **存活时长随暂停停住**：被暂停特效的剩余存活时间同时停住，解冻后从冻结点继续，不会在冻结中途到期消失。
- `freeze_layers.particles` 为假（缺省）时粒子照常推进。
- **没有粒子暂停原语的适配层**：存活时长倒计时仍恒停住（不取决于适配层能力）；视觉上的暂停由适配层的可选原语提供，没有时可用二维渲染契约的通用兜底装饰器——有时间缩放口时粒子停在原处，没有时暂停等于画面上消失、恢复等于按原参数重发（循环类特效无缝接上，非循环特效重播剩余时长）。见 [ADR-0129](../adr/0129-顿帧冻结特效与粒子的可选能力接口.md) 的 M4 增补。

## 6. 挥空与空挥反馈

判定相结束（`action.marker{active_end}`）时本攻击实例命中数为零 → 反馈绑定缺省规则播 `whiff` 层与可选的挥空特效；有命中则不播。这是"打空了"的可感知信号，与 03 的回避类结局（打到了但被闪避）分开。

两条补充规则：

- **只有带攻击的动作才有挥空**：`action.started.isAttack` 由规则层按技能内容给出（含伤害类或投射物效果，或声明了 `hit`/`release` 标记即为真）。闪避、纯位移、纯增益动作没有"打空"，不开挥空窗口、不播 `whiff` 层。没有收到过 `action.started` 的动作实例按带攻击处理。
- **投射物动作的挥空等投射物的结局**：动作发射了投射物时，判定相结束不立即定挥空——此刻弹还在飞。反馈侧收到 `action.projectile_launched` 后保留窗口，等该动作实例的所有投射物都发出 `action.projectile_ended`：期间或之后任何命中确认都使窗口计数为正，即不挥空；最后一发结束时全程零接触，才补播挥空（落在投射物结局那一刻）。结局原因为 `Cleared`（清场、换图）只放弃等待，不算挥空。

## 7. 测试与验收

假适配层记录调用时间线，期望值由规则算出：

1. 反馈包按 `(class, outcome)` 选变体，缺项按规定顺序回落。
2. 幅度类字段按 `amountRatio` 曲线、暴击与击杀倍率缩放，结果等于公式值。
3. 群体：同一 tick 多次命中镜头冲击恰好一次；`camera_impulse_min_interval_ms` 内的第二次被丢弃；音效不超过并发名额与每 tick 上限。
4. 合成上限：多次同向冲击叠加后相机侧合成幅度不超过 `camera_shake_cap`，反向冲击互相抵消，随衰减余量回来；退化通道同样受限。
5. 镜头：前瞻点随速度方向，死区内不动，分轴阻尼下的轨迹等于一阶滞后公式（只有一级滞后）；不支持冲击能力时退化为 `shake` 并有诊断记录。
6. 距离衰减：`none` 不衰减，`linear:<跨度>` 的系数等于 `1 - 距离/跨度`，裸 `linear` 不衰减且提示一次。
7. 顿帧：被冻结实体的剪辑帧号在冻结期间不变，其它实体照常；`freeze_layers.particles` 为假时粒子继续推进。
8. 回避类结局不触发 `impact` 层与命中特效；零命中时触发 `whiff` 层。
9. 缺省规则：游戏没有 `PlayImpact` 规则时一次命中恰好一次镜头冲击（幅度等于手感规则算出的值）；游戏有自己的规则时只有那一次；关掉缺省规则时没有。
10. 玩家强度：系数 0 时对应出口幅度为零，其余反馈不受影响；系数 0.5 时幅度减半。
11. 脚步：剪辑声明标记时只由标记出声（几何步幅被抑制），没有声明时由几何步幅出声；材质由脚下区域决定，无该材质的行时退回通用行；档位 0 两者都不出声。
12. 标记：`trail_start`/`trail_end` 开关拖尾与残影，`fx:<id>` 播对应特效，`impact` 放行推迟的闪白（超时没有标记则照常闪）；同名重复标记各自触发。
13. 实验室：`feel_av_feedback` 脚本在 `lab_av` 打击包与 `linear:6` 衰减下记录缩放脉冲与震动的时间线（基线逐位固定）；宿主侧的缩放脉冲、震动、闪白系数、残影与重复关键帧由引擎端运行期测试验收。
