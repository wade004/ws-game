## 1. 打击反馈包（`feedback.impact_profile`）

一条记录把一次命中的全部表现打包，由 `combat.hit_confirmed` 驱动，两种结算模式共用：

```
struct ImpactProfile {
  id: Id
  variants: Map<(impactClass, outcome: hit|crit|kill|avoided), ImpactVariant>   // 缺项按 outcome 回落 hit，再按 impactClass 回落 medium
}
struct ImpactVariant {
  flash: Optional<{profileId, target: target|source}>           // 09 Flash 原语
  vfx: Optional<{vfxId, attach: contact|target|source, orient: contact_normal|world_direction|none, scale_by_ratio: 曲线引用}>
  sfx: List<{layer: swing|whiff|impact|sweetener|voice, tier: 1..N}>   // 层 + 强度档，映射到 sfx 表行（第 3 节）
  camera: Optional<{impulse_gain: 画面高度比例, shake_profile: Optional<Id>}>
  floating_text: Optional<{styleId}>                              // 09 第 6.2 节
  trail: Optional<{start: active_start|hit, end: active_end}>
  freeze_layers: {skeleton: true, particles: Bool, trail: Bool}   // 顿帧期间冻结哪些层（第 4 节）
  intensity: {ratio_curve: 曲线引用, crit_multiplier: Number, kill_multiplier: Number}   // 按 amountRatio/isCrit/isKill 缩放幅度类字段
}
```

- 反馈绑定新增动作 `PlayImpact(profileId | from_feel)`（09 第 6.1 节固定集合第八项）。`from_feel` 取受击方解析后手感表特效组的 `impact_profile_ref`，再按事件的 `impactClass`/`hitResult`/`isCrit`/`isKill` 选变体。框架缺省规则：`combat.hit_confirmed → PlayImpact(from_feel)`。
- `instant` 模式仍可用 `sync: hit_frame`（ADR-0017）把反馈延到命中帧；`timeline` 模式的命中本来就在接触时刻，缺省不同步。
- 后仰、倒地等身体反应不由反馈包决定，而由 `reaction` 字段选姿势键（04 第 2.2 节 `hit.*`）；反馈包只叠加闪白、特效与音画。
- 回避类结局（`avoided` 变体）只播挥空/格挡类反馈，**不播成功命中的完整反馈**。
- 慢动作不在反馈包里：击杀慢镜头由玩法层钩子对 `combat.hit_confirmed{isKill}` 发时间尺度请求（00 第 5 节）。

## 2. 镜头档案（`camera_profile` 扩展）

既有 `camera_profile` 表（09 第 3.5 节配置项）扩展跟随字段，全部呈现型：

| 字段 | 单位 | 说明 |
|---|---|---|
| `follow_lag_ms` | ms | 跟随滞后（换算为 `ICamera.follow` 的平滑系数） |
| `look_ahead` | 身高倍数 | 沿速度方向的前瞻距离；`look_ahead_lag_ms` 让前瞻点自身也有滞后，避免反转时甩动 |
| `dead_zone` | 身高倍数（宽、高） | 目标在死区内镜头不动 |
| `damping_x` / `damping_y` | ms | 分轴阻尼 |
| `combat_zoom_delta` / `combat_zoom_blend_ms` | 倍率 / ms | 进出战斗的缩放变化与过渡 |
| `impulse_gain` | 画面高度比例 | 镜头冲击基准幅度（乘反馈包的 `impulse_gain`） |
| `impulse_min_interval_ms` | ms | 冲击合并的最小间隔 |
| `shake_cap` | 画面高度比例 | 震屏与冲击叠加后的上限 |
| `distance_attenuation` | 曲线引用 | 按命中点到跟随目标的距离（身高倍数）衰减 |
| `user_intensity_setting` | 设置项引用 | 玩家可调的整体强度开关（含关闭），走 10 第 7 节设置文件 |

镜头系统（表现层，引擎无关）按档案算出目标点（前瞻、死区、阻尼），再调既有 `ICamera.follow`；冲击经可选能力 `supportsCameraImpulse` 的 `impulse(direction, magnitude, decayMs)`，不支持时退化为 `shake`（05 第 7 节降级）。幅度以画面比例计，随缩放自动换算，不跨投影直接复用世界距离。

## 3. 音效分层与限流

- 五个手感层：`swing`（挥动）、`whiff`（挥空）、`impact`（命中）、`sweetener`（增味，低频/高频点缀）、`footstep`（脚步，材质由地图区域标签决定）。每层若干强度档，`sfx` 表按 `(layer, tier, 可选材质)` 登记行；反馈包只引用层与档，不引用资源。
- 并发：沿 ADR-0105 的同层并发名额；反馈包层面另加 `max_impacts_per_tick`（同一 tick 超出的命中只播第一批的音效，其余静默）。
- 顿帧不影响音效播放（已发声的继续）。

## 4. 群体命中的合并（表现侧）

| 对象 | 规则 |
|---|---|
| 攻击方顿帧 | 判定型已取最大并限幅（03 第 3.2 节），表现只跟随 |
| 镜头冲击 | 同一 tick 合并为一次，方向取幅度加权和，幅度取最大；`impulse_min_interval_ms` 内的后续冲击丢弃；总幅度按 `shake_cap` 截断 |
| 音效 | 同层并发名额 + `max_impacts_per_tick` |
| 特效 | 每目标各自播放，`max_vfx_per_tick` 上限（缺省不限） |
| 闪白/后仰 | 每目标各自，不合并 |
| 飘字 | 既有合并规则（09 第 6.3 节） |

每个敌人的受击、伤害仍正常结算；未参与的角色默认继续模拟与播放。

## 5. 顿帧期间的表现

收到 `feel.hitstop_started{unitIds}`：冻结这些实体的动画时间轴（序列帧/骨骼必冻）与程序动画原语时间轴；粒子与拖尾按反馈包 `freeze_layers` 决定；其它实体、界面、调参面板、镜头照常。`feel.hitstop_ended` 解冻并从冻结点继续。表现帧不停，因此冻结中的实体仍可被闪白（闪白参数时间轴与动画时间轴分开）。

粒子与特效的冻结规则（`freeze_layers.particles` 为真时）：
- **属于谁**：以某个实体为宿主挂接的特效（挂在锚点或挂点上的持续特效：拖尾、光环、灼烧）属于该实体，随它冻结；以世界坐标/接触点/屏幕位置播放的一次性特效（命中闪光、屏幕特效）没有宿主，不冻。是否随单位冻结因此由特效怎么挂接决定，不在特效表里逐条声明。
- **状态而非快照**：冻结标记挂在单位上；冻结期间才播放的该单位特效（含资源尚在加载、加载完成后才真正播出的）同样从暂停状态起播；同一单位重复冻结/解冻幂等，不计数。
- **存活时长随暂停停住**：被暂停特效的剩余存活时间同时停住，解冻后从冻结点继续，不会在冻结中途到期消失。
- `freeze_layers.particles` 为假（缺省）时粒子照常推进。

## 6. 挥空与空挥反馈

判定相结束（`action.marker{active_end}`）时本攻击实例命中数为零 → 反馈绑定缺省规则播 `whiff` 层与可选的挥空特效；有命中则不播。这是"打空了"的可感知信号，与 03 的回避类结局（打到了但被闪避）分开。

两条补充规则：

- **只有带攻击的动作才有挥空**：`action.started.isAttack` 由规则层按技能内容给出（含伤害类或投射物效果，或声明了 `hit`/`release` 标记即为真）。闪避、纯位移、纯增益动作没有"打空"，不开挥空窗口、不播 `whiff` 层。没有收到过 `action.started` 的动作实例按带攻击处理。
- **投射物动作的挥空等投射物的结局**：动作发射了投射物时，判定相结束不立即定挥空——此刻弹还在飞。反馈侧收到 `action.projectile_launched` 后保留窗口，等该动作实例的所有投射物都发出 `action.projectile_ended`：期间或之后任何命中确认都使窗口计数为正，即不挥空；最后一发结束时全程零接触，才补播挥空（落在投射物结局那一刻）。结局原因为 `Cleared`（清场、换图）只放弃等待，不算挥空。

## 7. 测试与验收

假适配层记录调用时间线：

1. 反馈包按 `(impactClass, outcome)` 选变体，缺项按规定顺序回落。
2. 幅度类字段按 `amountRatio` 曲线、暴击与击杀倍率缩放，结果等于公式值。
3. 群体：同一 tick 多次命中镜头冲击恰好一次且幅度不超过 `shake_cap`；`impulse_min_interval_ms` 内的第二次被丢弃；音效不超过并发名额与每 tick 上限。
4. 镜头：前瞻点随速度方向，死区内不动，分轴阻尼下的轨迹等于一阶滞后公式；不支持冲击能力时退化为 `shake` 并有诊断记录。
5. 顿帧：被冻结实体的剪辑帧号在冻结期间不变，其它实体照常；`freeze_layers.particles` 为假时粒子继续推进。
6. 回避类结局不触发 `impact` 层与命中特效；零命中时触发 `whiff` 层。
7. 关闭用户强度设置后镜头冲击与震屏幅度为零，其余反馈不受影响。
