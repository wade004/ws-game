## 1. 原则

- 同一套控制机制可以产生轻快、稳定或沉重的移动。"重"优先由动画、步幅、声音和镜头表达（呈现型），其次才是加减速与制动距离（判定型）；**不为了"重"增加输入延迟**。响应型动作游戏的缺省预设是快速起步、快速急停。
- 真实速度、碰撞与控制延迟是玩法；步幅、倾斜、启停混合是表现。是否让不同角色有真实操作差异由游戏设计决定并记录在平衡配置里，框架只提供两边的机制。
- 位置在每个 tick 只由一个来源决定。移动、动作位移、击退、受控位移都经运动仲裁器，不允许多个模块在同一 tick 各自改位置。

## 2. 运动档案（判定型，档案"移动"组）

| 字段 | 单位 | 缺省 | 说明 |
|---|---|---|---|
| `accel_ms` | ms | 0 | 从静止达到目标速度的时间；0 即瞬时达速（既有行为） |
| `decel_ms` | ms | 0 | 从目标速度到停止的时间 |
| `accel_curve` / `brake_curve` | 曲线引用 | 线性 | 走 04 第 3.6 节曲线形态登记 |
| `reverse_policy` | `instant\|through_zero` | `instant` | 反向输入：立即反向（保留速率），或先减速到零再加速 |
| `turn_rate_deg_s` | 度/秒 | 0（瞬时） | 朝向（facing）的转向速率；朝向独立于移动方向（05 第 3.2 节） |
| `walk_speed_ratio` | 倍率 | 0.45 | `moveMode: walk` 的目标速度相对基础移速 |
| `sprint_speed_ratio` | Optional 倍率 | 无（按 1，与 `run` 等速） | 冲刺（`moveMode: sprint`，第 3.3 节）的目标速度相对基础移速的倍数；档案没写时冲刺与跑步等速 |
| `action_move_speed_ratio` | 倍率 | 0 | 动作进行中允许的移动速度倍率（0 即定身）；合成来源：攻击期间武器临时覆盖 |
| `action_turn_lock` | Bool | 真 | 动作进行中锁朝向（`turn_assist_deg` 对齐后不再转） |
| `keep_momentum_on_action_end` | Bool | 假 | 动作结束时保留残余速度还是清零 |
| `keep_momentum_on_motion_end` | Optional Bool | 假 | 动作位移窗口（`motion_end`）结束时，位移带来的速度是清零还是按 `decel_ms` 滑行（第 4 节）；缺省清零，即位移距离 = 声明值。可选字段：没有写它的预设行为不变 |
| `arrival_decel` | Bool | 真 | 路径跟随到达终点前按 `decel_ms` 减速（避免 AI 冲过路点） |
| `wall_slide` | Bool | 真 | 位移被阻挡截断时沿墙滑动（去掉法向分量），而不是整体停下 |
| `apply_to_path_following` | Bool | 真 | 运动档案是否也作用于目标类移动（AI/点击移动）；假则目标类移动保持瞬时达速 |
| `knockback_resistance_stat` | Optional<Id> | 无 | 读哪个属性作为击退抗性（0～1），未声明视为 0 |
| `unit_body_radius` | Optional 身高倍数 | 0 | 单位体积半径（标定后为世界单位）；大于 0 才参与单位间体积阻挡（第 3.5 节），0 或未写即该单位不阻挡别人也不被别人阻挡。可选字段：没有写它的预设行为不变 |
| `dodge_through_units` | Optional Bool | 假 | 动作位移穿过别的单位体积的总开关（第 3.5 节）；哪些位移种类穿过由 `pass_through_motion_kinds` 决定 |
| `pass_through_motion_kinds` | Optional 文本 | `dash,step_back` | 逗号分隔的动作位移种类名；`dodge_through_units` 为真时这些种类的动作位移穿过别的单位体积，其余种类不穿过；名字不认识读取档案时报错 |
| `unit_separation_speed_ratio` | Optional 数值 | 0.5 | 重叠分离速率，基础移速的倍数；0 即不被推开，也不推开别人（第 3.5 节） |
| `path_avoid_units` | Optional Bool | 真 | 路径跟随与追击被体积挡住时局部绕行；假则撞到即停（开 `wall_slide` 时滑一段） |
| `forced_push_units` | Optional Bool | 假 | 受控位移（击退等）被体积挡停时，是否把剩余位移按比例转给挡路的单位 |
| `forced_push_ratio` | Optional 数值 | 0.5 | 转移的比例：转移距离 = 剩余距离 × 比例 ×（1 − 被推单位击退抗性） |

全部缺省值合起来等于既有行为（瞬时达速、瞬时转向、无滑墙差异），没有运动档案引用的单位逐 tick 结果不变。

`MovementState`（05 第 6.2 节）新增字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `velocity` | Vec2 | 当前速度（世界单位/秒），加减速积分的状态 |
| `desiredDirection` | Vec2 | 本 tick 期望方向（来自输入轴或路径下一段） |
| `motionMode` | 第 3 节枚举 | 当前运动模式 |
| `motionSource` | `regular\|action\|forced\|none` | 本 tick 胜出的位移来源 |

## 3. 运动模式与运动仲裁器

### 3.1 运动模式

| 模式 | 进入条件 | 接受输入位移 | 允许转向 | 退出时保留动量 |
|---|---|---|---|---|
| `grounded` | 缺省 | 是 | 是 | — |
| `action` | 动作时间线进行中（01） | 按 `action_move_speed_ratio` | 按 `action_turn_lock` | 按 `keep_momentum_on_action_end` |
| `forced` | 击退、冲锋/跳跃/受控位移（ADR-0026 `move` 效果）、抛飞 | 否 | 否 | 否 |
| `staggered` | 硬直（03 第 4 节） | 否 | 否 | 否 |
| `rooted` | `movementLocked`（控制光环） | 否 | 是 | 否 |
| `frozen` | 局部顿帧叠加态（03 第 3 节），叠在任一模式之上 | 否 | 否 | 恢复原模式 |
| `dead` | 死亡 | 否 | 否 | — |

每行的三个布尔是 `feel.motion_mode_rules` 表的缺省值，游戏可改（例如允许硬直中缓慢转向）。闪避不是独立模式：它是带动作位移与无敌窗口的时间线技能，处于 `action` 模式；"闪避是否优先于某状态"完全由取消窗口与优先级决定，不天然优先。

### 3.2 仲裁顺序

tick 步骤 4（05 第 6.4 节内部顺序）在"再处理本 tick 存活的位移意图"之后、"真正推进位移"之前插入仲裁：

```
候选来源（本 tick 可能同时存在）：
  forced      ← 受控位移任务 / 击退任务（既有 ADR-0026 机制产出的本 tick 位移）
  action      ← 动作时间线的 motion 段（第 4 节）
  regular     ← 输入轴方向位移 或 路径跟随（既有"最后一条意图生效"规则在此内部适用）

胜出规则（固定优先级，一个 tick 恰好一个来源）：
  dead > frozen(零位移) > forced > staggered(零位移) > rooted(零位移) > action > regular
```

- 胜出来源给出"候选位移"，随后走既有导航裁决（`raycast` 截断到入射点前，截断后不可走则不位移；05 第 6.4 节 2026-09-09 勘误）。`wall_slide` 为真时，截断后把剩余位移投影到阻挡边切向再做一次同样裁决（最多一次，不递归）。
- `forced` 胜出期间既有路径挂起；结束后按 `resume_path_after_forced`（游戏级策略，缺省 `drop`，可选 `resume`）处理。
- 步骤 4 之外没有任何代码写单位位置（既有约束不变）。

### 3.3 积分

`regular` 来源的位移由运动档案积分：目标速度 = 单位移动速度属性 × 模式倍率（walk 取 `walk_speed_ratio`、run 取 1、sprint 取 `sprint_speed_ratio`（没写按 1）、动作中取 `action_move_speed_ratio`；本目录里的"基础移速"一律指这个属性，不是标定表的参考基础移速）× 控制效果；`velocity` 沿 `accel_curve` 在 `accel_ms` 内趋近目标、沿 `brake_curve` 在 `decel_ms` 内趋近零；`reverse_policy: instant` 时方向翻转不经过零；斜向恒归一化；位移 = `velocity × dt`。被阻挡截断时把 `velocity` 的法向分量置零（滑墙）或整体置零（不滑墙），保证下一 tick 不会重新撞上同一堵墙产生抖动。

`accel_ms = decel_ms = 0` 时以上退化为 `speed × dt`，与既有实现逐位一致。

**冲刺**：`moveMode` 取值 `walk | run | sprint`。冲刺与跑步同为自主移动（经运动仲裁的 `regular` 来源、同一套加减速与转向），只有目标速度倍率不同；移动请求（`MoveRequest.mode`）带 `sprint` 才进入冲刺，没有运动档案的单位冲刺与跑步逐位一致。"按住冲刺键冲刺、松开恢复"由**玩家移动意图解析器**完成（运动层本身不读按键）：宿主每个固定步把移动轴交给它，它在数据声明了冲刺输入动作（按钮型、类别 `move`，缺省 id `input.action.sprint`，01 第 2.1 节）且该键此刻按住、移动轴非零（轴向量平方长大于 `0.0001`，与此前各宿主手写的阈值一致）时给出 `moveMode: sprint` 的方向请求，否则给 `walk`（宿主要"默认跑步"时传 `run` 作基础模式，冲刺键仍可升到冲刺）；原地按住冲刺键不产生请求。按住状态在按键边沿到达（采样）时即时更新，与移动轴同一口径，同一固定步里"先采样输入、再解析移动请求"读到的就是本步的按键状态，没有晚一 tick 的滞后。数据没有声明冲刺动作时解析器给出的请求与此前宿主手写的 `walk` 方向请求逐位一致。冲刺的呈现侧见第 7 节（姿势键 `move.sprint`，缺失时回落到 `move.run`）。

### 3.4 朝向

- 朝向由 `turn_rate_deg_s` 限速趋近 `desiredDirection`（0 即瞬时）。
- 动作被接受时（01 第 2.3 节 `face_on_accept`）：朝向立刻对齐到按下瞬间的移动轴方向，但最多转 `turn_assist_deg`（档案动作组）；声明了目标辅助的动作改为对齐到辅助目标（第 5 节）。
- `action_turn_lock` 为真时动作进行中朝向冻结；`move` 类取消窗口打开并被使用时解锁。

### 3.5 单位间体积阻挡

本节的取舍与范围边界作为 [ADR-0116](../adr/0116-运动仲裁器与运动档案.md) 的追加决定登记在 [ADR-0128](../adr/0128-单位间体积阻挡.md)。可选能力，由档案字段 `unit_body_radius` 开启；没有声明的单位（含所有既有预设）不进入下面任何一条，既有算式一字不变。

- **成对语义**：两个单位都声明了半径时，中心距不得小于半径之和；只有一方声明则双方互不影响。体积是圆（二维平面），半径取自各自的档案（标定后为世界单位）。
- **连续扫掠**：本 tick 的位移当作线段（先撞墙滑动的位移当作"到墙前 + 沿墙滑一段"两段折线，逐段扫掠），与每个"不会动"的有体积的其他存活同图单位求首次进入；命中后停在入射点之前一个到达容差处（`ArrivalEpsilon`，与墙体阻挡同一约定），高速位移不会隧穿。起点已在别人体积内时，位移只拦"让距离变近"的，允许走开。
- **同 tick 顺序无关、跟随者不滞后**：结果与单位的创建顺序、意图提交顺序无关。会动的单位（走路、追击、被击退、做动作位移）之间的接触在 tick 末按各自的**最终位置**求解（不当静态障碍），不会动的单位是静态障碍，沿用上面的连续扫掠；"谁会动"取本 tick 实际是否移动的不动点，而不是 tick 起点按意图的预判（预判只是加速提示，预判错只多算几遍，不改结果）。
- **时间模型**：接触的几何是每个单位本 tick **实际走的折线**（先撞墙滑动的拐点、绕行点、路径逐路点、受控位移与动作位移都计入），时间取运动仲裁给出的速度剖面（输入位移的加减速斜坡、动作位移与受控位移的曲线）；匀速时与"起点 + 位移向量 × 比例"逐位相同。一个 tick 内多种位移来源叠加时没有可信的 tick 内形状，按匀速处理。求解的实现机制（可重放的求解遍、遍数上限、折线逐段求首次接触、宽相网格只缩小候选不改判定式）写在 `core/carriers/unit/README.md` 与 [ADR-0128](../adr/0128-单位间体积阻挡.md)，不属于本文的契约。
- **谁让路**：接触点上沿连线方向的速度分量决定"谁在靠近"。一方靠近另一方走开时只有靠近的一方让路（放慢到恰好贴着对方最终位置的体积边界外一个到达容差处），所以快的跟随者追上慢的单位时贴着对方的最终位置，既不滞后一个 tick，也不拖慢前面的单位；相向或擦过时双方按同一比例缩短。每个单位取各对要求的最小缩放比例迭代到收敛（不收敛则把仍冲突的单位归零），缩短后的位移仍须过地形，否则回到起点。被拉回的单位保留**沿接触面的切向速度**（不再整体清零，贴着对方滑行不会粘住），路径跟随的路径进度按实际走过的弧长恢复（本 tick 内路径被替换时仍回到旧路径上的正确点，已记下的到达被撤销）。位移的到达/受阻事件（`OnMoveStopped`）与 `unit.moved` 一样延后到 tick 末成对裁决之后、按（单位 id，发生先后）顺序、带最终位置发出。追击与朝目标的动作位移，有体积的单位读目标的 tick 起点快照而不是目标此刻的位置。单位的创建顺序和意图提交顺序因此不改变结果。
- **来源**：`regular` 中输入位移按 `wall_slide` 决定整体停下还是沿体积切向滑一段（最多一次，不递归；切向那段仍过地形裁决）；路径跟随与追击（`path_avoid_units`，缺省真）被挡后沿"目标方向去掉沿法向分量"的切向以剩余预算局部绕行，目标方向偏向的一侧被挡死、目标点落在挡路单位的体积里、或正对着撞上而两侧都走不动时停在体积前；`action`（动作位移）按声明的 `blocking`：`stop` 停下、`slide` 滑开；`dodge_through_units` 为真且位移种类在 `pass_through_motion_kinds` 里时整段穿过（缺省 `dash`、`step_back`，`lunge` 等不穿过）；`forced`（击退等受控位移）被体积挡住以"被阻挡"收场（不滑），`forced_push_units` 为真时剩余位移按 `forced_push_ratio` ×（1 − 被推单位击退抗性）转给挡路的单位，被推单位在**同一 tick** 获得一个沿连线方向的强制位移并用真实的受控位移推进（同 tick 多个推力向量相加，已在受控位移中的单位不再被推；一轮里被推单位互为"会动"，结果与处理顺序无关，连锁最多 8 轮，余下的退回下一 tick 起推进）。
- **重叠推开**：tick 末，相互重叠的单位按 `unit_separation_speed_ratio` × 基础移速的权重分摊深度，每个单位每 tick 位移不超过权重 × 步长，推到恰好不重叠为止；被冻结、被定身、死亡、处于受控位移中的单位权重为 0；推开的位移先过地形裁决，再过与别的单位的接触检测（不会被推进第三个单位或墙里）。穿过式位移（幽灵）在窗口内不被撞停、不参与分离，但别的单位的成对裁决把它的最终位置当作静止的体积；窗口的最后一个 tick，幽灵终点不得落在别人体积里，按就近可行位置修正（径向投影、圆周采样点、两个体积圆的交点，不进任何体积且可走），被中断的窗口（击飞、死亡、击晕打断）落在体积里的由分离推出。
- **追击**：追击停步距离取"声明的停步距离"与"双方半径之和加两个到达容差"的较大者，所以体积大于停步距离时站在体积边缘而不是撞上去。
- 离散步（回合制）不受影响；死亡单位不阻挡。

## 4. 动作位移

时间线技能的 `motion` 块：

```
struct ActionMotion {
  kind: lunge | dash | step_back | charge
  distance: Number                   // body_heights，标定后为世界单位；charge 类为最大距离
  curve: 曲线引用                     // 位移随 motion_start..motion_end 的进度曲线；内建曲线名，或 custom:<id> 引用导入期烘焙的 skill.motion_curve 行
  direction: facing | input_snapshot | toward_target
  max_turn_deg: Number               // 位移方向相对当前朝向允许的最大偏转
  blocking: stop | slide             // 受阻处理，同 ADR-0026 的裁决语义
}
```

- 位移只在 `motion_start`～`motion_end` 标记之间发生（01 第 3.3 节），逐 tick 经仲裁与导航裁决；受阻按 `blocking` 处理，永远不穿墙、不瞬移。
- **位移窗口结束时的速度**：窗口的最后一个位移 tick 之后，动作位移来源产生的速度立即清零，动作的净位移恰好等于声明的 `distance`（曲线积分到 1），不再叠加制动滑行。需要"冲出去再滑一段"的动作（滑铲、冲刺急停）在档案里把 `keep_momentum_on_motion_end` 设为真，此时窗口之后的速度按 `decel_ms` 衰减到零，滑行距离计入该动作的净位移而不在 `distance` 之内。这条与动作整体结束时的 `keep_momentum_on_action_end` 相互独立：前者管位移窗口末，后者管后摇结束。窗口末的清零只作用于动作自己产生的速度，顿帧冻结期间不吞掉这次清零（冻结解除后的第一个 tick 补做）。
- `charge` 类（冲向目标）距离上限、转角上限与有效时间三者都必须声明，到达目标身前 `stop_distance`（档案动作组）即停。
- **没有根运动驱动**：单位位置的权威只在逻辑层——位移由逻辑按距离与曲线逐固定步算出，是确定性的，与表现帧率、引擎动画求值无关（无头回放、指纹基线、重放都依赖这一点）。曾经设想的"适配层每表现帧回读剪辑根位移再累加"会让模拟结果依赖表现帧率，已删除（`driver: root_motion` 在加载期报错并给迁移说明；字段 `driver` 已废弃，缺省且唯一取值 `code`，可不写）。想要"位移形状来自动画"的作者走导入期烘焙：导入工具（`import_assets bake-motion`）把剪辑沿前进方向的根位移采样（时间 → 累计距离）归一成单调不减的断点表，写进数据表 `skill.motion_curve`（`id`、`points`、仅溯源的 `source_clip`/`source_distance`），动作位移声明 `curve: custom:<行 id>`，`distance` 取烘焙报告给出的位移（身高倍数）；运行期运动层按固定步求值，与内建曲线同一条路径，逻辑层不读剪辑、不读骨骼。曲线只增不减（倒退的采样噪声被抹平）；真要往回退的位移拆成两个动作位移。

## 5. 目标辅助（软锁定）

建立在空间命中之上的可选能力，不是目标选择式结算的替代：

- 动作定义 `target_assist: {chain_ref, max_distance, max_angle_deg, mode: face_only | close_distance}`。
- 动作被接受时用目标选择链（06 第 5 节）解析候选，取第一个在 `max_distance` 与 `max_angle_deg` 内的目标：`face_only` 只把朝向对齐到它（不超过 `turn_assist_deg`）；`close_distance` 还把本次 `lunge` 的距离缩放到"判定相形状恰好覆盖目标"所需的值（不超过 `distance` 上限，仍经导航裁决）。
- 发 `action.target_assisted{actorId, castInstanceId, targetId, facingDelta, distanceAdjust}` 供实验室显示；没有候选时静默。
- 硬锁定（持续锁定一个目标并绕其转向）是游戏层在此之上的可选包，框架只保证解析链与朝向接口可复用。

## 6. 击退、抛飞与倒地的运动侧

- 击退距离由打击反馈的**判定型**那半决定：`feel.weapon`/受击组的 `knockback_distance`（body_heights）× (1 − 目标击退抗性) × 冲击等级倍率；方向取 `combat.hit_confirmed.worldDirection`（03 第 2.4 节），无接触点时取攻击方到目标方向。
- 执行走既有 `move` 效果的 `knockback` 子类型（连续模式，ADR-0026）：`forced` 来源、`ease_out` 曲线、导航裁决截断。命中批次里多个目标各自独立击退。
- 抛飞/倒地是受击裁决（03 第 4 节）的结果状态：运动侧同为 `forced`，附带倒地时长与起身动作的姿势键（04）。
- 击退不叠加：目标已处于 `forced` 时新的击退按 `knockback_stack: replace | ignore`（游戏级策略，缺省 `replace`）。

## 7. 步态与移动呈现参数（呈现型派生）

逻辑层没有步态概念，只有 `moveMode`（walk/run/sprint 决定目标速度）与 `velocity`。表现层按 `|velocity| / 基础移速` 的比值（下称速度比）派生步态，用于姿势解析（04 第 2 节）：

| 步态 | 条件（档案移动组阈值，带滞回） |
|---|---|
| `idle` | 比值 < `idle_max_ratio`（缺省 0.05） |
| `walk` | < `walk_max_ratio`（缺省 0.6） |
| `run` | 其余 |
| `sprint` | ≥ `sprint_min_ratio`（声明了冲刺时） |

滞回 `gait_hysteresis_ratio`（缺省 0.05）避免在阈值附近抖动。以下四个呈现型字段（半属隔离：表现层只读呈现那一半，不读判定型字段）由表现层消费，运行期取值与限制如下：

- **步幅速率 `stride_scale`**（缺省 1）：移动剪辑的播放速率 = `stride_scale` × 速度比 ÷ 该步态剪辑的参考速度比，夹到 0.5 到 2.0，取整到 0.05 的整数倍；单位停下（速度比为 0）时恢复为 1。参考速度比表示"这条剪辑是按多快的移动制作的"：走档取 `walk_max_ratio`，跑档取 1，冲刺档取 `sprint_min_ratio`（没声明取 1）。限制：参考比随步态档变化，起步加速经过档位切换时速率会跳变，不是单调的；剪辑每循环位移（04 第 4 节）是导入校验的对照项，不进运行期。
- **启停混合 `start_blend_ms` / `stop_blend_ms`**：单位在待机与移动之间切换时，切入剪辑的交叉淡入时长（毫秒）。优先级：每对键声明（`display.anim_set.blends`）> 本字段 > 目标剪辑逐键声明（`blend_ms`）> 默认 0.15 秒；只覆盖"待机 → 移动"与"移动 → 待机"两种切换，不影响别的切换。限制：只对 `model` 型骨骼剪辑生效（序列帧播放器不做交叉淡入）。存在 `move.start`/`move.stop` 过渡剪辑时仍先播过渡剪辑（04 第 3 节），本字段是没有过渡剪辑时的混合时长。
- **前倾 `lean_deg_per_accel`**（缺省 0 即不倾）：身体前倾角（度）= 每秒速度比加速度 × 本字段，加速前倾、减速后仰，经一阶低通（时间常数 0.08 秒）平滑，总倾角夹在 45 度内，取整到 0.25 度。限制：只作用于 `model` 型骨骼外形（作为角色外形根节点的俯仰），序列帧外形保持直立，不报错。
- **重映射动作的播放速率**：动作被速率重映射（加速类属性、体型/武器的分相倍率、动作时长下限夹取，01 第 3.5 节）时，表现层对该动作各相位的剪辑播放速率 = 作者毫秒 ÷ 重映射后实际毫秒（实际毫秒 = tick 数 × 步长），由 `action.started` 事件带出三个相位的速率、`action.phase_changed` 切换相位时换速率；动作结束或被取消后恢复为 1。所以重映射不会让动画与判定时间线脱节（速率 × 实际相位长度 = 作者相位长度，04 第 5 节的同一系数）。

脚触地标记（`footstep`）的归属与发布见 04 第 5 节。

## 8. 测试与验收

无头宿主、输入脚本驱动、期望值由档案公式算出：

1. 起步：`accel_ms = A`、线性曲线，达到目标速度的 tick 数 = `ceil(A / 步长)`；`A = 0` 时首 tick 即满速且与既有实现逐位一致。
2. 急停：松开输入后停止距离 = 曲线积分值（线性曲线为 `v × decel / 2`），误差不超过一个 tick 的位移。
3. 反转：`instant` 策略 180° 反向当 tick 速率保留；`through_zero` 策略先经过零。
4. 斜向：任意方向轴输入的速度模长恒等于目标速度。
5. 滑墙：沿墙斜向推进时位置沿切向单调推进，法向分量为零，无来回抖动。
6. 仲裁：击退进行中输入位移无效；顿帧中位移为零且解冻后恢复原模式；`forced` 结束后路径按策略丢弃或恢复。
7. 动作位移：`lunge` 距离等于标定后的档案值；受阻按 `blocking` 截断；曲线引用 `custom:<id>` 解析不到时加载期报错，位移形状与烘焙断点表一致；数据里写 `driver: root_motion` 加载期报错并给迁移说明。
8. 目标辅助：候选在角度内时朝向转角不超过 `turn_assist_deg`；`close_distance` 缩放后判定相首 tick 形状覆盖目标。
9. 步态：速度跨阈值时步态切换恰好一次（滞回）；冲刺稳态速度 = 基础移速 × `sprint_speed_ratio`；移动剪辑的播放速率 = `stride_scale` × 速度比 ÷ 参考速度比（夹取、取整后）；重映射动作各相位的播放速率 × 实际相位长度 = 作者相位长度；前倾角在加速时为正、减速时为负、总量不超过 45 度。
9a. 按住冲刺：解析器在冲刺键按住且轴非零时给 `sprint` 请求、松开恢复 `walk`，稳态速度等于基础移速 × `sprint_speed_ratio`（期望由档案行算出）；没有声明冲刺动作时的请求与手写 `walk` 方向请求逐字段相同（比较用例）；原地按住不产生请求；换成按住的实验室脚本与点按冲刺脚本的稳态速度一致。
10. 路径跟随开 `arrival_decel` 时到达终点不越过路点；关 `apply_to_path_following` 时 AI 移动与既有实现逐位一致。
11. 单位体积：开启 `unit_body_radius` 的两个单位，任意 tick 中心距不小于"半径之和与上一 tick 中心距的较小者"（减允差）；撞停位置 = 对方位置 − 半径之和 − 一个到达容差之内；未声明时轨迹与未开启逐位一致；穿过仅在 `dodge_through_units` 为真且种类在 `pass_through_motion_kinds` 里时发生。重叠按 `unit_separation_speed_ratio` 推开：中心距逐 tick 单调不减、增量不超过两个单位的速率上限之和、到半径之和为止、不穿墙。路径跟随与追击绕过体积到达目标，窄道或目标点在体积里时停下且不摆动。受控位移推人的转移距离 = 剩余距离 × 比例 ×（1 − 抗性）。同 tick 顺序无关：打乱单位创建与意图提交顺序，逐 tick 位置与位移停止事件流（含位置）逐位一致；"谁会动"的预判设成全部会动、全部不动、随机或取反，结果逐位一致。先撞墙滑动又撞体积的折线位移，对静止与走动的单位都放行只和直线弦相交的体积、拦住只在第二段上的体积。跟随者同速跟随时轨迹与独自行走逐位一致，更快的跟随者追上后贴着前面单位的最终位置。位移到达/受阻事件里的位置等于该 tick 末单位的最终位置。被成对裁决拉回的单位保留沿接触面的切向速度、路径进度不倒退。穿过式位移的终点不落在别人体积里。（求解机制的逐项用例见单位模块 README。）
