# 手感设计 — 目录导读

> 目的：本目录收录游戏技术基础架构的手感（game feel）设计文档集——一份总纲，加输入与动作、移动与运动仲裁、攻击受击与命中、姿势与动画契约、手感档案与解析、手感实验室与验收、镜头与音画反馈七份专题文档。走路、移动、转向、攻击、受击、各武器与各姿势的手感由此成为框架的一等交付物：新游戏选预设、填标定、进实验室校准，不再重新开发手感机制。结论性的决策已落成 ADR-0113～0120。

## 1. 定位与边界

本目录遵守 [00_架构总则](../00_架构总则.md) 的全部硬性规则：技术无关、游戏无关，不出现引擎、语言、框架、工具名，不出现具体游戏代号。手感在框架与游戏层之间的分界是一句话：**机制、档案结构、分层解析、原型库、姿势规格、实验室归框架；标定值、最终美术、主观微调归游戏。**

"直接用"的含义：新游戏不再重新开发任何手感机制，并复用在兼容条件下验证过的预设与姿势集；它不承诺任何模型、动画、镜头与设备组合都不需要试玩微调，也不以复用百分比作承诺或验收指标。

4. [03_攻击受击与命中.md](03_攻击受击与命中.md) — 两种结算模式并存、空间命中、命中确认事件、局部顿帧、受击裁决、群体合并。
