## 1. 定位与边界

本目录遵守 [00_架构总则](../00_架构总则.md) 的全部硬性规则：技术无关、游戏无关，不出现引擎、语言、框架、工具名，不出现具体游戏代号。手感在框架与游戏层之间的分界是一句话：**机制、档案结构、分层解析、原型库、姿势规格、实验室归框架；标定值、最终美术、主观微调归游戏。**

"直接用"的含义：新游戏不再重新开发任何手感机制，并复用在兼容条件下验证过的预设与姿势集；它不承诺任何模型、动画、镜头与设备组合都不需要试玩微调，也不以复用百分比作承诺或验收指标。
