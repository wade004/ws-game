## 0. 定位与边界

本文档是方法指导文档，不是框架交付物清单。它回答"数值怎么推、怎么验"，不回答"某个游戏的数值是多少"。

| 基础架构提供 | 游戏层提供 |
|---|---|
| 公式形态、曲线表结构、当量写法、预算与校验机制、仿真骨架 | 曲线表里的数、锚点表里的数、权重、带宽、阈值、场景清单 |
| 校验器抓结构性错误（单调、成环、超预算、份额之和） | 收支平衡、每级时长目标、内容配平 |

00 第 4 节"基础架构提供 / 游戏层提供"里"全部通用系统的机制"与"具体游戏的数值"的分界，在本文档的落法是：**公式归框架，系数归游戏；写法归框架，数归游戏。**

## 1. 主线：统一自变量与统一价值单位

五个模块的公式虽多，原理只有一条：

- **统一自变量是等级。** 角色等级、怪物等级、物品等级三者通过"期望装备等级曲线"（输入角色等级，输出该等级玩家身上装备的期望物品等级）绑在一起。任何曲线表的横轴都是这三种等级之一。
- **统一价值单位是秒伤当量。** 属性经权重表折成"属性点当量"，属性点当量经派生规则与技能系数折成"秒伤当量"。技能预算、装备预算、控制与增益的价值、经验与金钱的当量，全部用这一个单位计。

由此得到的推论：任何两个数值对象只要都能折算到秒伤当量，就可以比较、可以定价、可以校验。

## 2. 五段推导

推导顺序固定，每段的输出是下一段的输入：

```
锚点  →  曲线  →  预算  →  静态校验  →  动态仿真
```

| 段 | 输入 | 输出 | 归属 |
|---|---|---|---|
| 锚点 | 设计意图（每级期望生命、期望秒伤、击杀时长、被杀时长、期望装备等级、每级时长） | 锚点表 | 表结构归框架，数归游戏 |
| 曲线 | 锚点表 | 预算曲线、成长曲线、等级曲线、换算曲线、价值曲线等一切曲线表 | 表结构归框架，数归游戏 |
| 预算 | 曲线表 + 权重表 | 每件装备、每个技能允许的价值上限 | 公式归框架 |
| 静态校验 | 内容数据 + 曲线表 | 阻断或警告 | 校验器归框架 |
| 动态仿真 | 内容数据 + 锚点表 + 智能释放优先级表 | 击杀时长分布、成长轨迹、离群值报告 | 骨架归框架，场景与阈值归游戏 |

## 3. 五条原则

1. **曲线单调。** 一切以等级为横轴的曲线单调递增且有限，校验器阻断非单调、非有限。
2. **一切相对量。** 份额、当量、倍率、系数、比例是内容数据的写法；绝对数只出现在曲线表里。曲线一改，全部内容自动跟随。
3. **每个数都有消费者。** 每条属性、每条曲线至少被一个机制读取，没有消费者的不存在（校验器警告）。
4. **每个公式可反推。** 填时长得经验，填秒伤得怪物血量，填期望装备等级得期望属性。工具可以从任一端推另一端。
5. **尺度无关。** 保守版与变态版只改曲线与显示格式，不改任何公式；百分比属性必经换算曲线，恒等曲线是保守版的特例。

## 4. 公式清单（按推导顺序）

以下只固定形态与变量名，全部系数由数据配置。

### 4.1 锚点

每级一行：期望生命 `HP(L)`、期望秒伤 `DPS(L)`、击杀同级普通怪时长 `TTK(L)`、被同级普通怪击杀时长 `TTD(L)`、期望装备等级 `E(L)`、目标每级时长 `T(L)`、期望击杀间隔 `G(L)`、任务与探索经验占比 `Q(L)`。

### 4.2 怪物

```
怪物血量(L, 分档) = DPS(L) × TTK(L) × 分档属性倍率
怪物伤害(L, 分档) = HP(L) ÷ TTD(L) × 分档属性倍率
```

### 4.3 属性（ADR-0030）

```
最终值 = ( 基础值 + Σ flat ) × ( 1 + Σ pct ) × Π ( 1 + 独立乘区_i )
派生属性基础值 = Σ ( 来源属性最终值 × 派生系数 )          ← 两轮拓扑序聚合，派生无环
百分比属性最终值 = 换算曲线( 点数, 单位等级 )               ← 换算层始终存在，恒等曲线为默认
```

### 4.4 装备（ADR-0032）

```
预算上限 = 预算曲线(物品等级) × 品质预算倍率 × 槽位系数
实际消耗 = ( Σ ( 属性值_i × 权重_i ) ^ k ) ^ (1/k)         ← k 默认 1.5，数据配置
护甲值   = 护甲曲线(物品等级) × 槽位系数                    ← 不占预算
武器秒伤 = 秒伤曲线(物品等级) × 品质预算倍率 × 武器槽位系数
伤害范围 = 武器秒伤 × 初始攻速 × ( 1 ± 浮动 )
期望属性(L) = 等级成长(L) + Σ槽位 预算反解( E(L), 期望品质, 槽位 )
```

### 4.5 技能（ADR-0031）

```
效果值 = 基础值 + Σ ( 缩放属性最终值 × 系数 )               ← 基础值可选引用等级曲线，默认 0
武器百分比伤害 = 武器秒伤 × 一拍常数 × 百分比               ← 一拍常数为记账单位，不是锁
施放时间当量 T = max( 动作时长, 一拍常数 )
技能预算 = DPS(L) × T × 冷却溢价(冷却 ÷ T) × 范围折价(最大目标数) × 消耗溢价(消耗 ÷ 期望回复率)
控制价值 = 时长 × 目标数 × 控制类别权重
增益价值 = 属性当量 × 时长 ÷ 冷却
```

### 4.6 战斗

```
命中 = 攻击者命中属性 − 目标闪避属性 − 等级差表.未命中(Δ)   ← Δ = 目标有效等级 − 攻击者有效等级
暴击 = 暴击属性 − 等级差表.暴击压制(Δ)
减免 = 减免曲线( 护甲或抗性, 目标等级 )
伤害 = 效果值 × 暴击倍率 × 施法者乘区 × ( 1 − 减免 ) × 目标乘区（含按来源类别读取的减免）
```

### 4.7 经验（ADR-0033）

```
击杀经验 = 击杀基数(怪物等级) × 分档经验倍率 × 难度经验倍率 × 等级差表.经验系数(Δ)
任务经验 = 当量 N × 击杀基数(任务等级) × 等级差表.经验系数(Δ)
探索经验 = 1 × 击杀基数(区域等级)
升级所需(L) = 击杀基数(L) × 每级怪当量(L) × ( 1 + Q(L) )    ← 每级怪当量 = T(L) ÷ ( TTK(L) + G(L) )
```

### 4.8 金钱（ADR-0034）

```
基准价值 = 价值曲线(物品等级) × 品质价格倍率 × 槽位价格倍率
买价 = 基准价值；售价 = 基准价值 × 售价比例
怪物掉钱 = 金币基数(怪物等级) × 分档倍率 × 难度掉落倍率
任务金币 = 当量 N × 金币基数(任务等级)
复活费 = min( 当前余额, 按策略计算值 )                        ← 复活永不被金钱阻断
```

## 5. 锚点表与对账等式

秒伤有两种算法：

- **自上而下**：锚点表直接写 `DPS(L)`。
- **自下而上**：由 `E(L)` 与期望品质经预算反解得期望属性，经派生规则与技能系数，按智能释放优先级表算出实际秒伤。

两者必须在带宽内相等，生命同理：

```
| DPS_自上而下(L) − DPS_自下而上(L) | ÷ DPS_自上而下(L) ≤ 带宽
```

这条等式是整套数值合理性的最终归宿：怪物血量按自上而下的秒伤定，若自下而上的秒伤偏低，玩家打怪就慢，反之就快。静态校验保证单件内容对得上曲线，只有仿真能验这条等式。

## 6. 静态校验级别汇总

| 级别 | 检查项 | 登记处 |
|---|---|---|
| 阻断 | 装备实际消耗超预算；模板属性 + 词缀最大份额超预算；曲线非单调或非有限；派生成环；引用不完整；单条词缀份额之和超一；品质倍率大小顺序与品质排序不一致；技能预算比值超硬上限且无超模说明 | 04 第 5 节 |
| 警告 | 技能预算比值超出带宽；装备预算利用率过低；授予价值超特效占比；主动技能动作时长为零且未声明为反应类；手填价格偏离公式；属性无消费者 | 04 第 5 节 |

校验器抓的是手滑，不抓意图。装备的超预算全是手滑，所以阻断；技能的超预算多数是意图，所以警告，用硬上限把手滑单独分出来。

## 7. 动态仿真（ADR-0035）

仿真运行在无头运行时上（11 第 6 节集成测试用桩适配层驱动世界模拟；ADR-0003 保证同种子同输入同结果），由小到大三级：

| 级 | 输入 | 输出 | 验什么 |
|---|---|---|---|
| 战斗仿真 | 标准玩家（等级 + 职业，装备按 E(L) 反解，技能按技能书填满，策略为智能释放优先级表）对生物模板按指定等级出生；N 个种子 | 击杀时长、被杀时长、命中率、资源曲线、技能输出占比的分布；越级矩阵（玩家等级对怪物等级 ±k）胜率与时长热图 | 锚点自洽；等级差表形状 |
| 成长仿真 | 战斗仿真结果；掉落按种子掷骰；每级按怪当量击杀、按占比做任务 | 每级实际时长对目标、装备等级对 E(L)、命中率随等级、金币累积 | 曲线与来源的组合效应 |
| 内容覆盖仿真 | 每个技能、装备、生物模板 | 技能预算比值、装备评分对同级同槽位中位数、生物对标准玩家的击杀/被杀时长；离群值列表按偏离排序 | 警告级校验的评审入口 |

三个关键设计：

- **智能释放既是功能也是策略模型。** 仿真用的优先级表与玩家一键释放用的是同一张，仿真结果即真实玩家的下限体验；手动操作强于它是设计空间。
- **确定性让仿真结果可当基线。** 每次运行存一份报告，数据改动后重跑对比，输出统计量差异；这是数值回归，与回放回归同一原理，比对对象从事件流换成统计量。
- **先表格后仿真。** 对账等式可先在表格里手算；表格算不对的仿真一定不对，表格算对的仿真抓组合问题。

## 8. 设计自测流程

游戏层每一轮数值工作按以下顺序自测，前一步不过不进下一步：

1. 填锚点表（或改锚点）。
2. 手算或用工具从锚点推出曲线表，先在表格里验对账等式。
3. 填内容（属性、技能、装备、生物、任务、商人）。
4. 跑数据校验：阻断项清零。
5. 跑内容覆盖仿真：逐条处理离群值，超模的填超模说明。
6. 跑战斗仿真：锚点自洽在带宽内，越级矩阵形状正确。
7. 跑成长仿真：每级时长、装备等级轨迹、命中率、金币在带宽内。
8. 存基线；后续改动以差异报告评审。

## 验收标准

1. 五个模块（ADR-0030～0035）里的每一条公式都能在本文档第 4 节找到对应形态，且变量名一致。
2. 给定任一条曲线表，能说出它的锚点来源与消费者；给定任一件内容，能说出它受哪些阻断/警告校验。
3. 对账等式在任一等级上可由两条算法分别算出并比较，仿真报告能给出该比较结果。
