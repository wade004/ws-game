## 1. 魔兽的装备设计梳理

### 1.1 一件装备的骨架

**槽位。** 3.3.5 有十九个装备位，衬衫和战袍纯外观；后期删掉远程槽和圣物，格子越来越少。

**护甲类型。** 布皮锁板加盾牌，护甲值由类型、物品等级、槽位查表得出，不占属性预算。大灾变加了"穿本职护甲全套给百分之五主属性"，用奖励代替限制。

**品质。** 灰白绿蓝紫橙加传家宝。品质只做两件事：决定预算倍率，决定属性条目数。它不决定属性种类。

**物品等级。** 一切数值的唯一自变量：护甲值、属性预算、武器秒伤、售价、修理费、需求等级全部是它的函数。这是魔兽装备设计最重要的一条。

**需求。** 角色等级需求与物品等级挂钩，加职业限制、专业限制。

### 1.2 属性怎么定量

**预算。** 每件装备的属性预算由物品等级和品质算出，再乘槽位系数。属性各有权重，合并时带约一点五的指数，堆单一属性会被惩罚。

| 项 | 大致规则 |
|---|---|
| 预算随物品等级 | 近似线性增长，品质抬斜率 |
| 大件槽位系数，胸腿头 | 满额 |
| 中件槽位系数，肩手腰脚 | 约四分之三 |
| 小件槽位系数，腕颈背戒指副手 | 约一半出头 |
| 属性合并指数 | 约一点五 |

**属性条目。** 通常主属性加耐力再加一到两条副属性。**附加层**：宝石、附魔、重铸，在预算之外再叠一层玩家可控的微调。**武器**走秒伤预算：秒伤由物品等级和品质决定，伤害范围等于秒伤乘攻速再浮动；攻击强度按标准化攻速折入，防止慢速武器把瞬发技能吃肥。**特效与授予**：装备时生效的光环、使用时释放的技能、命中触发的效果，饰品几乎全靠这个；套装按件数解锁效果。**随机后缀**："熊的""鹰的"，一组按预算配好的属性包，同一模板出多种版本。

### 1.3 来源、经济与演进教训

**装备等级带。** 来源分层对应物品等级段：普通怪掉绿，精英蓝，五人本蓝，团队本紫。满级之后物品等级接替角色等级成为成长轴，这是"毕业装"概念的来源。

**经济锚。** 售价、购买价、修理费、分解产出都是物品等级和品质的函数。**外观与数值分离**：幻化是后期最受欢迎的改动之一。

演进中砍掉的东西，每一条都是教训：

| 砍掉的 | 原因 |
|---|---|
| 重铸 | 换一件装备要重算一遍，太琐碎 |
| 大部分宝石槽 | 微调层太厚 |
| 远程槽、圣物、衬衫战袍属性 | 格子多不等于深度 |
| 命中、精准等阈值副属性 | 必须堆到线的属性不好玩 |
| 随机战火、泰坦 | 同一件装备反复刷更好版本，玩家反感 |

六条精髓：物品等级是唯一自变量；品质是预算倍率不是属性种类；槽位系数让戒指和胸甲可比；合并指数惩罚单一属性堆叠；装备是属性的主要来源，满级后装备等级接替角色等级；装备是技能与被动的载体。

## 2. 单机方案

### 2.1 骨架：槽位、护甲、品质、等级带

- **槽位缩到十个**（游戏层默认值建议：头、胸、腿、手、脚、项链、戒指、饰品、主手、副手）。槽位定义表加两列：槽位系数、是否武器位。系数示意：胸腿双手武器 1.0，头手脚单手武器 0.75，饰品类与副手 0.5。
- **护甲值不占预算**：护甲曲线(物品等级) × 槽位系数，仅护甲位。护甲类型与职业穿戴限制不做，靠职业被动奖励引导（用户确认）。
- **品质五档**（白绿蓝紫橙），灰色只做杂物不做装备。品质定义表加三列：副属性条数（可选，不填不限）、特效预算占比、价格倍率。品质倍率顺序须与排序权重一致。
- **装备等级带挂在角色等级上**：锚点表增加"期望装备等级 E(L)"曲线，来源分层是它的偏移（普通怪低几级绿、精英与任务同级蓝、Boss 高几级紫）。需求等级由物品等级经曲线反推。满级后由难度层的物品等级偏移接手。属性章节"装备落后就打不中"走的正是这条曲线。

### 2.2 数值：预算、条目、武器、特效

**预算公式补齐消耗侧。** 07 此前只定义了上限，没有定义"实际属性消耗"怎么算：

```
预算上限 = 预算曲线(物品等级) × 品质倍率 × 槽位系数
实际消耗 = ( Σ ( 属性值_i × 权重_i ) ^ k ) ^ (1/k)         ← k 默认 1.5，数据配置
```

权重来自属性权重表，百分比属性先经换算曲线折回点数。校验加"预算利用率过低"警告抓漏填。

**属性条目数不限制**（用户修正：不是技术问题，由具体游戏自由发挥）。品质定义的条数列改为可选。主属性由职业模板的主属性引用决定掉落时给哪条。

**武器走秒伤预算。** 武器秒伤 = 秒伤曲线(物品等级) × 品质倍率 × 武器槽位系数；伤害范围 = 武器秒伤 × 初始攻速 × (1 ± 浮动)。**攻速只给初始值**（用户修正："三档"是我的表述不清，指初始值建议而非限制成长）：成长靠急速属性作用于动作时长，上限是急速的硬上限，并受表现层动画最短时长约束。武器百分比伤害原语改为基于"武器秒伤乘一拍常数"，一个常数替代魔兽整套标准化攻速。

**特效与授予。** 紫以上才可带授予；授予的技能或光环走技能预算校验，预算等于该件预算乘品质特效占比，警告级；橙装独特技能免校验，靠超模说明登记意图。套装只给职业毕业装做，效果通过授予被动光环实现。

**装备评分共用同一公式。** 实际消耗公式换成职业权重就是装备评分，服务比较箭头、一键换装最优、掉落升级提示。玩家看到的是评分而非物品等级与品质两个数。

### 2.3 扩展点的取舍

| 扩展点 | 结论 | 理由 |
|---|---|---|
| 随机词缀 | 本版启用 | 单机内容量最大的解药，一个模板出多版本 |
| 附魔、宝石、重铸 | 不做 | 魔兽自己砍掉的微调层，对低门槛目标是负资产 |
| 耐久 | 不做 | 金币回收职责由复活费承接（金钱章节） |
| 绑定 | 不做 | 字段留着，无运行期语义 |
| 外观与数值分离 | 天然满足 | 09 装备外观表本来就独立 |

### 2.4 随机词缀怎么和等级、品质相处

核心一句话：**品质决定预算有多少，词缀决定预算怎么花。词缀永远不碰物品等级和品质。**

- **词缀是份额包，不是绝对数值。** 词缀定义写"占该件预算的比例，以及这份预算按什么属性组合分配"。具体数值在掉落那一刻按该件装备的预算算出，一条词缀自动适用于全部等级。
- **模板预留词缀份额。** 模板自己的属性只花掉一部分预算，剩下的留给词缀。校验"模板属性加词缀最大份额不超预算"为阻断级。
- **牛逼的词缀是"对路"，不是"更多"。** 同样占三成预算，双属性、带小特效、职业专属的组合更稀有，稀有度体现在池内权重，不体现在总量。
- **想让某次掉落更强，改的是品质。** 掉落时三次独立掷骰：物品等级来自来源，品质来自掉落表品质权重，词缀从该品质对应的池里抽。"幸运掉落"就是品质骰子掷高了，装备显示为蓝色，预算随品质变大，一切仍在公式内。

## 3. "高等级装备一定更好"能保证吗

### 3.1 对策划填错：能保证

保证来自三层：

1. **校验器抓结构性错误，阻断级。** 模板属性超预算、模板加词缀最大份额超预算合不进去。针对曲线本身补几条：预算曲线单调有限、品质倍率顺序与排序一致、单条词缀份额之和不超一、需求等级曲线单调。
2. **编辑器实时显示预算利用率。**
3. **仿真抓尺子本身的错。** 曲线结构合法但数值荒唐（某段预算翻倍），校验器判断不了，只有"同级玩家穿期望装备打同级怪"的仿真能发现。

三个边界：总量单调不等于对每个玩家单调（同预算不同属性组合，这是配装乐趣）；品质会让等级比较失真（显示层统一用装备评分）；特效是唯一的口子（警告级，特效预算占比守门）。

### 3.2 对修改器：不保证，也不该保证

内存修改器在离线单机上无法防也不值得防；00 的取舍表已经写了"反作弊直接去掉"，10 的回放章节写了"不涉及反作弊"。但两条设计让修改器只能改眼前这一局：

- **属性值不落盘。** 10 第 2.5 节已定"属性快照默认不存，读档时重新聚合"。物品实例存实例 id、模板 id、堆叠数、品质、词缀引用，不存任何属性数值。内存里改成一百万，存档存的仍是"模板某某、词缀某某"，读档按数据重算。
- **确定性模拟让回放校验成为可能。** 联机或排行榜的反作弊正道是对方或服务端拿同一份数据和输入流重跑一遍。联机时双方交换物品身份，各自按本地数据重算，任何来自对方的绝对数值一律不信。

"保证"要说准：它是内容管线的不变量，不是运行期的安全属性。

## 验收标准

1. 任一装备的实际消耗与预算上限可手算，超预算的内容无法通过校验。
2. 任一条词缀定义可在任一物品等级上落出具体数值，且总量等于该件预算的份额。
3. 存档中不存在任何算出的装备属性值，读档后属性与掉落时一致。
