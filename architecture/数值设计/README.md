## 1. 定位与边界

本目录遵守 [00_架构总则](../00_架构总则.md) 的全部硬性规则：技术无关、游戏无关，不出现引擎、语言、框架、工具名，不出现具体游戏代号。数值设计在框架与游戏层之间的分界是一句话：**公式归框架，系数归游戏；写法归框架，数归游戏。** 收支平衡、每级时长目标、内容配平、锚点数值、带宽与阈值全部是游戏层的事，本目录只给方法、公式形态、表结构、校验机制与仿真骨架。

参考系与全架构一致：以魔兽世界 3.3.5 的真实设计为主要参照，后期资料片的演进作为教训吸收。

## 2. 阅读顺序

1. [00_数值总纲.md](00_数值总纲.md) — 先建立"统一自变量是等级、统一价值单位是秒伤当量、锚点→曲线→预算→校验→仿真五段推导"这条主线，其余文档都挂在它上面。
2. [01_人物属性.md](01_人物属性.md) — 属性是一切数值的地基：派生、换算、作用域、等级差表、权重表都在这里定。
3. [02_技能.md](02_技能.md) — 效果值契约与技能预算，消耗与节拍锁。
4. [03_装备.md](03_装备.md) — 预算消耗公式、槽位与品质、词缀份额包，装备是属性的主要来源。
5. [04_经验.md](04_经验.md) — 等级曲线与经验来源，等级是所有曲线的横轴。
6. [05_金钱.md](05_金钱.md) — 价格挂物品等级，水龙头与下水道的框架边界。
7. [06_仿真与自测.md](06_仿真与自测.md) — 计算原理主线与三级仿真，数值合理性怎么验。
