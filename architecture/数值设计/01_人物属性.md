## 1. 魔兽世界的属性分类与设计意图

以巫妖王 3.3.5 为主参考，因为框架的参考系就是那一版的服务端结构。

| 类别 | 属性 | 作用 | 谁消费它 |
|---|---|---|---|
| 主属性 | 力量、敏捷、智力、耐力、精神 | 不直接参战，按职业系数换算成派生属性。力量给攻击强度和格挡值，敏捷给攻击强度、暴击、闪避、护甲，智力给法力上限和法术暴击，耐力给生命，精神给回复 | 派生换算 |
| 派生属性 | 攻击强度、法术强度、生命上限、法力上限、护甲、回复速率 | 结算管线直接读的数值 | 结算管线、资源池 |
| 评级属性 | 命中、暴击、急速、精准、穿透、韧性、防御、精通 | 装备只给"评级点数"，按单位等级换算成百分比。同样点数在高等级换出的百分比更少，旧装备自然贬值 | 命中表、结算管线 |
| 抗性 | 火、冰、暗、自然、奥、圣 | 走饱和曲线换算成减免百分比 | 结算管线减免步 |
| 资源池 | 生命、法力、怒气、能量、符文能量、连击点 | 技能的消耗与回复 | 施法管线 |
| 隐藏上下文 | 武器伤害与攻速、移动速度、仇恨系数 | 不显示为属性，但公式里用 | 结算、AI、移动 |

3.3.5 的量级感受：

| 换算 | 大致值 |
|---|---|
| 耐力到生命 | 1 点约 10 点生命 |
| 力量到战士攻击强度 | 1 点换 2 点 |
| 智力到法力 | 1 点约 15 点 |
| 80 级暴击等级换 1% | 约 46 点 |
| 80 级急速或命中等级换 1% | 约 33 点 |

魔兽这套设计的四个意图：

- **主属性换算是职业差异化的机制。** 同一件加力量的装备，战士和法师拿到的价值完全不同。数据只写一次，差异由职业系数产生。
- **评级换算是通胀控制器。** 十几年的资料片装备不断升级，如果直给百分比，暴击早就堆到一百。换算曲线让百分比随等级自动缩水。
- **每个属性有且只有一个消费者。** 闪避被命中表读，护甲被减免步读，回复被资源池读。没人读的属性不存在。
- **属性全部折算成同一预算单位。** 物品等级决定一件装备的属性预算，各属性有权重，合并时带一个约 1.5 的指数惩罚堆单一属性。这是装备平衡的真正依据。

后期教训：熊猫人到德拉诺期间，暴雪删掉了命中、精准、精神、护甲穿透、防御等级，把副属性收缩到暴击、急速、精通、全能。删的原因是两类属性不好玩：一类是"必须堆到阈值否则打不中"的属性，一类是"堆了也感觉不到"的属性。

## 2. 单机 RPG 的取舍与用户约束

单机和魔兽的三个根本差异决定裁剪方向，但其中两条经用户修正：

| 差异 | 初始判断 | 用户修正后的结论 |
|---|---|---|
| 没有 PvP | 韧性整个去掉 | 不能完全去掉，要为后续联机对战留扩展口 → 属性作用域字段 + 结算上下文来源类别 |
| 没有长期装备通胀 | 评级换算继续关闭，百分比直给加硬上限 | 框架不能替游戏决定数值尺度（保守版/标准版/变态版）→ 换算层始终存在，恒等曲线为默认 |
| 没有坦克治疗输出三角 | 缩减纯坦克属性 | 保留；主属性到派生的职业系数必须保留 |
| 命中 | 去掉，闪避放怪物侧 | 保留：跨等级刷怪就是打不中，装备落后就是打不中，需要玩家自己提升 |

单机推荐属性分类（游戏层默认值，非框架硬编码），六层：

1. **主属性**四个：力量、敏捷、智力、体质。玩家可见，升级成长和装备主要加这些。
2. **派生属性**：攻击强度、法术强度、生命上限、护甲、资源回复速率（资源上限固定后不再派生，见第 3.7 节）。
3. **战斗百分比属性**小集合：暴击率、暴击伤害、急速、闪避、命中。装备直给点数，经换算曲线。
4. **防御与减免**：护甲走减免曲线，元素抗性按 00 的口径作为可选维度。
5. **资源池**：现有 PowerSet 已覆盖。
6. **杂项**：移动速度、仇恨系数、回合制的先攻、单机特有的幸运或掉落加成。

魔兽属性到单机方案的对照：

| 魔兽 | 单机取舍 | 框架落点 |
|---|---|---|
| 五主属性 | 缩为四个，去精神 | 类别为主属性的定义行 |
| 攻强、法强、生命、护甲 | 保留 | 类别为派生的定义行加派生规则 |
| 暴击、急速评级 | 保留，经换算曲线 | 百分比类别加换算曲线引用 |
| 命中 | 保留，走等级差曲线 | 百分比类别 + 等级差规则表 |
| 精准、穿透、防御 | 去掉 | 无 |
| 韧性 | 不做属性，留作用域口子 | `scope: from_player` |
| 精通 | 不做通用机制 | 游戏层用光环实现 |
| 六系抗性 | 可选维度 | 现有可选策略 |
| 资源类型 | 可配置 | 现有 PowerSet |

## 3. 方案

### 3.1 属性定义增加类别与派生规则

`stat.definition` 新增 `category`、`derived_from`、`clamp`、`conversion_ref`、`scope` 五个字段（字段表见 06 第 1.3 节）。主属性和攻击强度在框架眼里不再是两个互不相关的数。

### 3.2 聚合改为两轮拓扑序

第一轮：无派生来源的属性完成三段式聚合。第二轮：派生属性的基础值等于各来源最终值乘系数之和，再走自己的三段式。这和魔兽一致：力量先变攻击强度，攻击强度再吃百分比加成。校验器新增"派生无环"阻断项。职业系数由职业模板覆盖：战士的力量换攻击强度系数是二，法师是零。

### 3.3 换算层始终存在，恒等曲线为默认

数值尺度落到框架上只有两处：点数怎么换成百分比，大数怎么存怎么显示。

| 尺度 | 曲线形态 | 效果 |
|---|---|---|
| 保守版 | 恒等加硬上限 | 装备写多少百分比就是多少，堆到上限截断 |
| 标准版 | 等级索引除数，魔兽评级式 | 同样点数在高等级换出更少百分比，装备随等级贬值 |
| 变态版 | 饱和曲线，除数随等级增长 | 点数堆到上亿也收敛不到一百，永远有堆的意义，永远堆不满 |

换算曲线契约固定为"输入点数与单位等级，输出百分比"，与护甲减免曲线同形态。变态版还要过三关：数值表示（框架明确 64 位浮点，有效数字约十五位，超出量级的游戏在游戏层选型分段单位或大数表示）；值域校验归游戏层（沿 ADR-0021）；百分比段膨胀用既有独立乘区分组拆开相乘。

为什么平衡方法不受尺度影响：锚点是击杀时长这类相对量，属性权重是相对权重，预算是"该等级应有属性总量"的比例。保守版和变态版跑的是同一套推导链，只有曲线除数、成长曲线斜率和显示格式不同。

### 3.4 来源类别作用域（韧性口子）

魔兽韧性的本质只有一句话：受到玩家来源的伤害与暴击时额外减免。它不是新系统，是结算管线里"目标乘区"步骤多读了一个按来源分类的属性。口子这样留：

- 结算上下文带"来源类别"，由载体类型给出，联机时细化。
- 属性定义的 `scope` 字段取值通用、仅对玩家来源、仅对生物来源。韧性就是作用域为玩家来源的两条属性。单机里没有玩家来源的伤害，这两条永远读不到，零成本。
- 控制递减留在光环叠加规则的策略钩子，不进属性层。
- 联机对战真正的前提在确定性，沿 ADR-0003 预留的定点数学 ADR 另行处理。

### 3.5 命中保留，等级差规则表

魔兽 3.3.5 的做法：攻防双方各有一个技能值等于等级乘五，基础未命中率固定，每点技能差再加一小段；斜率分两段，差距两级内每点加得很少，超过两级陡增。暴击同样被等级差压制。

本框架的设计：

- 命中判定 = 攻击者命中属性 − 目标闪避属性 − 等级差表.未命中加成(Δ)，Δ 为目标有效等级减攻击者有效等级。
- 同表再出一条暴击压制：越级打怪不仅打不中，也打不出暴击。
- 双向生效：怪物打高等级玩家同样吃惩罚。这是"越级刷低级怪毫发无伤"与"低级怪打不中高级玩家"的同一来源。
- 装备落后导致打不中，两条路都留，默认只走第一条：命中属性本身来自装备，装备落后命中就低，锚点保证"同级装备刚好够用"；显式路径"有效等级 = 角色等级 + 装备等级偏移"作为策略配置项默认关闭，理由是和第一条叠加会惩罚两次。
- 同表的经验系数与灰名界线供经验模块使用，目标名字五色同源。
- 表现层要配套目标等级差颜色与命中率提示。

### 3.6 属性权重表

`stat.weight`：属性 id → 一点主属性当量，可按职业覆盖。三个消费者：装备预算消耗、技能控制/增益价值、装备评分与自动配装。属性章节留位，装备章节是第一个正式消费者。

### 3.7 资源上限固定，回复速率派生

技能章节定了"一条资源条，上限固定不成长"，属性章节相应修正：派生属性列表中"资源上限"改为"资源回复速率"。上限来源字段仍支持引用属性，某个游戏要成长上限是数据选择。

## 验收标准

1. 给定任一属性，能说出它的类别、来源（派生或直给）、换算曲线、作用域与消费者。
2. 同一份属性定义在保守版与变态版尺度下不需要改动，只换曲线表。
3. 等级差表在命中、暴击、经验、目标颜色四处读的是同一张表。
