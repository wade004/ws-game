# editor

本目录是「GF 内容编辑器」——一个 Windows 桌面程序，用于编辑基于本框架（`architecture/` 文档集）立项的任意一款 `<game>` 的全部内容数据（技能、光环、物品、生物、掉落、任务、对话、遭遇、本地化等 [04_数据与内容管线.md](../architecture/04_数据与内容管线.md) 登记的全部数据表）——的产品文档与后续实现落点。

编辑器的产品文档已完成：[docs/编辑器产品文档.md](docs/编辑器产品文档.md)（markdown 版，正式产品方案）与 [docs/编辑器产品文档.html](docs/编辑器产品文档.html)（离线 HTML 版，供不便打开 markdown 的读者浏览，随 markdown 版同步更新）。用户已于 2026-09-09 拍板：本阶段暂不落地编辑器实现，当前本目录只保留这两份产品文档；实现立项、详细 UI 设计、开发排期待用户后续另行通知启动，以这两份文档的确认结果为起点。

产品文档遵循仓库全局约束：不出现任何具体引擎/语言/框架等技术名的限制**不适用于本目录**（`editor/` 不在 `architecture/` 目录内），但架构层面的结论仍以 `architecture/` 为唯一权威来源，本目录的文档只引用、不改写；文档中一律用 `<game>` 占位具体游戏代号，不出现任何真实游戏名。
