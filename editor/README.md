# editor

**本目录定位（v2，2026-09-09）**：编辑器产品文档与编辑器相关 ADR 的落点。编辑器基础套件与编辑器模板在独立的「编辑器项目」（独立仓库，独立语义化版本，按版本号锁定本框架的发布产物）；编辑器实例（每款游戏具体使用的编辑器工程）在各游戏自己的仓库（`<game>/editor/`，从编辑器模板复制而来）。**框架仓库（本仓库）不承载任何编辑器代码**——本目录不含、也不会含编辑器的可执行程序或源码，只保留产品文档与本决策记录的落点。三层结构与各层职责详见产品文档第 3 章"三层结构与职责划分"。

「GF 内容编辑器」用于编辑基于本框架（`architecture/` 文档集）立项的任意一款 `<game>` 的全部内容数据（技能、光环、物品、生物、掉落、任务、对话、遭遇、本地化等 [04_数据与内容管线.md](../architecture/04_数据与内容管线.md) 登记的全部数据表）。

编辑器的产品文档：[docs/编辑器产品文档.md](docs/编辑器产品文档.md)（markdown 版，v2.5，正式产品方案，见文档"变更记录"）与 [docs/编辑器产品文档.html](docs/编辑器产品文档.html)（离线 HTML 版，供不便打开 markdown 的读者浏览，同步至 v2.5；本仓库无 markdown→HTML 自动转换脚本，HTML 版变更记录表与第 4.1 节"契约面清单"表按 md 版逐次手工同步，其余章节未随 v2.3～v2.5 改动、保持原样）。用户已于 2026-09-09 拍板：编辑器实现不进框架仓库、跟随具体游戏走（"一个游戏一个编辑器"），本目录只保留产品文档；编辑器项目、编辑器模板与首个游戏的编辑器实例的实现立项、详细 UI 设计、开发排期待用户后续另行通知启动，以本文档的确认结果为起点。

产品文档遵循仓库全局约束：不出现任何具体引擎/语言/框架等技术名的限制**不适用于本目录**（`editor/` 不在 `architecture/` 目录内），但架构层面的结论仍以 `architecture/` 为唯一权威来源，本目录的文档只引用、不改写；文档中一律用 `<game>` 占位具体游戏代号，不出现任何真实游戏名。文档中引用的 [ADR-0018](../architecture/adr/0018-编辑器随游戏走与框架为此提供的交付物.md)、[ADR-0019](../architecture/adr/0019-复合字段子结构登记为机器可读schema.md) 已于 2026-09-09 拍板落库，收入 `architecture/adr/`。
