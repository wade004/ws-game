# API 参考

按命名空间列出各类库的公开类型；点进类型可看到它的字段、属性、方法、事件与继承关系，
以及源码 `///` 注释里写的用途说明。

范围：`Core.sln` 里的类库（`Core.Foundation`、`Core.Numbers`、`Core.Rules`、`Core.Carriers`、
`Core.Gameplay`、`Core.Sim`、`Presentation.Common`、`Adapters.Stub`、
`Adapters.Unity.DiagnosticsForwarding`）。Unity 适配层 UPM 包由 Unity 编译、不在 `Core.sln` 里，
**未纳入**本参考。

概念层面的说明（模块职责、判断记录）在 [模块说明](../../../README.md) 里。
