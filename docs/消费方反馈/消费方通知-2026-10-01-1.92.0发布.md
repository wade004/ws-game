## 行为收紧清单（升级时请逐条核对自己的调用与数据）

以下每条的共同点：此前被静默接受（或静默吞掉）的输入，现在抛异常或被拒绝；方括号内是抛出的类型/处理方式。

- `ArchetypeRegistry.ApplyTo`：未知职业/种族/天赋树此前在部分属性写出之后才抛，现在写入前整批校验、writers 零调用 [`ArgumentException`]；同一单位重复 `ApplyTo` 现在抛 [`InvalidOperationException`]。
- `InputMapHost.ImportBindings`：任一条非法（未知动作、值非数组、元素非字符串、绑定格式非法）此前非法项之前的合法项已生效，现在整批拒绝、状态与脏标记保持导入前 [异常类型不变]。
- `SfxPlayer` 层满时：新音优先级严格低于该层全部在播实例，此前会顶掉高优先级在播音，现在不播、返回空句柄、记诊断并计入丢弃计数；首次加载超时判定由墙钟改为 `Update(dt)` 累计。
- `shake_camera` 缺失 preset（无生效档或当前档无该 preset）：此前抛 `ArgumentException` 被吞成无上下文诊断，现在向 `FeedbackSinkDiagnostics` 记警告并跳过本次震屏（`profile_id` 语义定为当前相机档 `shake_presets` 的 preset id）。
- 相机跟随目标被销毁：此前 `CameraHost.Update` 每帧抛，现在保持最后有效位置并只记一条诊断，目标重现后自动恢复。
- `ShellHost.LoadGame`：读档成功但场景路由被拒，此前静默吞掉，现在读档仍算成功，但 `LoadResult.SceneRouteFailed`/`SceneRouteError` 置位并记警告。
- `ShellHost.NewGame` 存档写失败（返回 `false`）：此前难度已切、起始状态已建，现在难度三项状态回滚，并调用可选的 `NewGameRollback`（未注入则只记诊断说明游戏层状态未回滚）。
- `ViewBinder`：单个视图抛异常此前会中断整轮，现在逐视图隔离，只记诊断、其余视图照常；`view.Destroy()` 失败也会从绑定表移除该实体。
- `AreaTriggerHost`：区内实体被销毁时现在补发 `reason=despawned` 的 `area.trigger_left` 并清"已进入"记录（此前从不发出，`GetActiveTriggerIds` 会残留已销毁实体）。
- 表现层 8 个构造器形参传 null 现在在构造期抛 [`ArgumentNullException`]（此前到使用处才抛 `NullReferenceException`）：`ResourceReferenceTracker(loader)`、`InteractPathProvider(registry)`、`UiActionInvokedEvent(actionName)`、`UiLayoutDefinition(fields)`、`NumericValidationRuleDescriptor` 的 `ruleId`/`checkName`/`gradingItemName`/`group`。
- `CreatureFactory.SpawnCore`：`PowerFloors` 的键不在实际注册集合内，现在在注册实体之前抛 [`InvalidOperationException`]（此前世界实体残留）；`AddEntity` 之后任一登记步骤抛出现在原子回滚（异常原样上抛、零残留）。
- 数值写入口拒绝 NaN/Infinity [`ArgumentOutOfRangeException`，在任何状态变更前拒绝、不发事件]：`StatHost.SetBase`/`AddModifier`/`SetDerivationCoefficientOverrides`、`PowerHost.ModifyPower`/`Advance`/`AdvanceAll`/`SetMinOverride`、`RegenModifier` 构造、`ProgressionHost.GrantFromSource(multiplier)`。
- `ProgressionHost`：`AddXp` 溢出抛 [`ArgumentOutOfRangeException`]；存档 `Load` 的 level 超 int、`RestoreState`/`Load` 的 xp 为负数或已达本级升级门槛抛 [`FormatException`]。
- `FactionMatrix.SetReaction(from==to)`：现在抛 [`ArgumentException`]，不写入、不发事件。
- 枚举解析只认枚举名（精确匹配，拒绝数字串与组合串）：`QuestPersistable`、`DifficultyHost`、`MovementTickHandler` 的 mode/blocking、`AppStateMachineConfig`。
- `PowerHost.Reload`、`DroppedLootPersistable.Load`、`RulesAssembly.ReloadArchetypeAndRace` 改为原子：先全量解析/校验再提交，失败时旧状态不变（掉落台账与世界实体 id 冲突时既有掉落不再被销毁）。
- `RngStreamState` 拒绝四个字全零：构造函数抛 [`ArgumentException`]，`TryParse`/`Parse` 视为非法格式（存档里全零的 `rng.stream_states` 条目现在整体读档失败），`RngHost.SetStreamState` 拦截 `default(RngStreamState)`。
- `SettingsStore.Load`：`settings_version` 超 int 范围现在按文件损坏处理、退化为空设置（此前被 `(int)` 截断可能误触发迁移）。
- 音量入口：`SetVolume`/`SetLayerVolume` 对 NaN/Infinity 抛 [`ArgumentOutOfRangeException`]，有限值裁剪到 [0,1] 且持久化裁剪后的值，未知层名抛 [`ArgumentException`] 且不写新键；`ISettingsStore.Save` 返回 false 时记一条诊断。
- `WorldSim.Tick` 重入：阶段处理器/事件订阅者里嵌套调用 `Tick` 现在抛 [`InvalidOperationException`]（此前内层整拍完整执行）；`dt`/`scale`/`duration`/`factor` 为 NaN 现在被"不能为负"守卫拒绝；`SimClockHost` 构造函数现在校验 `DefaultTimeScale`；`Intent.Kind` 不再放过结尾换行。
- `AppStateHost` 回调异常：`OnStateChanged`/`OnSubStateChanged` 回调抛异常现在被隔离并经 `IAppLifecycleDiagnostics.Error` 记一条，不再穿透给 `RequestTransition`/`PushSubState`/`PopSubState` 调用方；回调内重入迁移的通知按发生顺序送达。
- `PlaybackQueue`：`Sequential` 下某步抛异常现在记诊断后继续、队列清空时照常触发 `Finished`（此前最后一步抛异常使 `PlaybackFinishedEvent` 永不发出）；`FloatingTextMerger.Update` 多个到期窗口改按插入顺序派发（此前倒序）。
- `ProjectileHost.Spawn` 速度 <= 0：现在告警并跳过（此前生成永不过期的僵尸/反向投射物）。
- 四处字段超 32 位整数范围现在抛带字段路径的 [`DataFieldException`]（此前 `(int)` 静默回绕）：`AchievementCriterion.count`、`EconomyDataParser.stock_limit`、`DifficultyTierDefinition.item_level_offset`、`TargetChainDef.max_targets`；`FeedbackRule.OptionalEnum`/`OptionalId` 非法枚举/标识字符串现在抛带字段名的 [`DataFieldException`]（此前静默变 null）。
- `UiPathParser`：下标超 int 范围、非 ASCII 数字、结尾 `$` 吞尾随换行，现在均按"无法解析"返回 false。
- `PresentationAssembly.Dispose`：单个子系统释放抛异常现在只记诊断、继续释放其余、最后重抛第一个异常（此前第一个抛出即中断、其余泄漏）。
- `ToString` 固定 `InvariantCulture`：`Vec2`、`Rect`、`SimStep`、`AnimClipEventSpec`、`Direction`（此前 de-DE/sv-SE 等文化下输出逗号小数或 U+2212 负号）；若你的代码依赖旧的非不变文化输出，会变。
- 行为变化（非抛出）：`StubSpatialQuery.QueryShape(Line)` 改矩形带口径，端面外的实体不再被线形命中；`GobjPendingLootPersistable.Load` 坏形状改为保持台账不变并记 Warn（`count` 非法丢弃该条记 Warn，不再抛）；`UiPanelHost` 面板 `Hide()` 现在真正隐藏（面板物体改为拉伸节点并作为 `Construct` 的父节点，硬编码的子路径要加一层 `Dialog/`）。

## 只增 API 清单

均为只新增，旧签名原样保留并转调，旧实现/旧编译的消费方不改也能编译、运行：

- 默认接口成员（旧实现不用改）：`ICameraFollowTarget.TryGetPosition(entityId, alpha, out position)`、`IWorldSim.RemoveEntityImmediately`、`IProgressionHost.UnregisterUnit`。
- 构造重载：`CameraHost` 五参（注入诊断出口）、`ShellHost` 十一参（带 `IPresentationDiagnostics`）与十二参（带 `NewGameRollback`）、`AudioLayerVolumeHost` 五参、`PlaybackQueue(double, IPresentationDiagnostics?)`。
- 新类型/成员：`LoadResult.SceneRouteFailed`/`SceneRouteError`/`WithSceneRouteFailure(string)`、`NewGameRollback` 委托类型、`PresentationAssemblyOptions.NewGameRollback`、`AudioLayerVolumeHost.Diagnostics`、`PlaybackQueue.Diagnostics`。

## `seed` 字段数字/字符串双写法

`SimBaseline`/`SimReport` 的 JSON 里，`seed` 此前是数字（经 double 往返，超过 2^53 丢精度），现在 `ToJson` 写成**十进制字符串**；`SimBaseline.Parse` 同时接受字符串与数字（旧基线写法）。仓库内已入库的基线不重写，`--update-baseline` 重写时才变成字符串。**若你自行解析基线/报告 JSON 的 `seed` 字段，请同时接受数字与字符串。**

## 发布流程变化（框架侧，消费方通常无需操作）

- `build.ps1 -Release` 的 `-ReleaseSkipUnity` 开关**已删除**，发布时不能再整段跳过 Unity；

  全量通过记录，否则拒绝发布（`-DryRun` 只警告）。
- 发布门禁固定带 IL2CPP 三步（构建 + 两种冒烟）；全量门禁新增环境矩阵两步、用例数下限、
  `games/_template` 数据根严格校验。
- 若你的项目复刻了本仓库的发布脚本或依赖 `-ReleaseSkipUnity`，请按上述变化调整。
