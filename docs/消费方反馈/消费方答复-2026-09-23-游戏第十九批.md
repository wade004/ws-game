## 反馈 1：粒子发射支持叠加混合（ADR-0074）

**做法：`vfx.def` 加一个可选字段，不在发射调用点上加参数负担。**

- 数据面：`vfx.def` 新增可选字段 `blend_mode`，取值 `alpha`/`additive`，**缺省即 `alpha`**，
  与改动前逐字一致——既有 `vfx.def` 行不需要改任何一个字节。
- 契约面：`Core.Foundation.EngineAdapter.IRenderer2D.EmitParticle` 新增一个带混合模式参数的重载，
  声明为**默认接口方法**，默认实现转发到既有 3 参重载并固定按 `Alpha` 处理。你方若自带
  `IRenderer2D` 实现（或测试替身），不需要改动任何一行即可继续编译通过。
- 适配层：按混合模式为特效序列播放器的渲染实例切换材质；`additive` 使用适配层内置的占位材质与
  自定义叠加混合着色器，随包分发，构建脚本已同步补齐——你方不需要自己造材质或着色器。

**实测**（真实序列帧特效资源 + `blend_mode: additive` 数据驱动播放）：渲染材质确实切到叠加混合材质
（着色器 `GameFoundation/Vfx/AdditiveUnlit`）；不声明或声明 `alpha` 时材质与改动前完全一致；
对象池复用同一播放器组件时材质按当次混合模式正确重设，不残留上一轮取值。

**为什么不做成"逐发射调用传混合模式"**：同一条 `vfx.def` 的混合模式是这个特效资源自身的属性，
不是每次播放的临时决定；写在数据里，内容侧改一处即可，不需要每个调用点都记得传。

## 反馈 2：`stop_vfx` 反馈动作（ADR-0075）

**做法：`play_vfx` 的镜像动作，字段形状对齐，不新增任何句柄概念给内容侧。**

- `FeedbackActionKind` 固定枚举新增第七项 `StopVfx`；`feedback.binding` 可声明 `stop_vfx` 动作。
- 字段形状**镜像 `play_vfx`**：`vfx_id` / `from_display` 二选一，`attach` 取 `source` / `target`。
  `attach: world` **不接受**——世界坐标播放的特效没有"挂在谁身上"这个可停止的锚，内容侧写了会在
  加载期报错而不是运行期静默无效。
- `IFeedbackSink` 新增 `StopVfx(vfxId, attach)`，同样是**默认接口方法、空实现**，既有实现方不受影响。
- 停哪一个：合成反馈接收端按 `(特效逻辑 id, 附着实体)` 维护**最近一次**播放句柄（覆盖式单句柄），
  语义是"停最近一个"，不是"停全部"——内存占用有界，不会随播放次数增长。查不到在播实例时静默返回、
  不产生诊断（光环已自然到期回收后再收到 `aura.removed` 是正常时序，不该报错）。

**随附修掉一个既有缺陷**：特效播放器的内部停止调用此前不幂等，对已自然回收的句柄重复调用会抛异常。

**实测**：一条 `play_vfx` 规则起播后，另一条独立 `stop_vfx` 规则触发即可观察到该特效实例真正停止。
`data/_sample` 里已带一对成对示例（`aura.applied` 起播 / `aura.removed` 停止 `vfx.sample_aura_glow`），
可直接照抄。

## 反馈 3：`combat.damage_dealt` 补 `skillId`（ADR-0073）

你方的核实结论完全正确：框架此前**不存在任何事件同时携带"是哪个技能"与"打中了哪个单一目标"**——
`combat.damage_dealt` 有 `targetId` 没 `skillId`，`skill.cast_success` 有 `skillId` 但目标是列表、
且反馈绑定器不解析列表字段。

**做法**：`CombatDamageDealtEvent` 新增**可空** `SkillId` 属性，取值经效果上下文的 `SkillId` 原样转发。

- 光环周期伤害等不经技能结算路径的伤害：**为空**（不伪造一个 id）。
- 普通攻击命中：携带框架原生保留 id **`skill.native_auto_attack`**。它不对应任何真实注册的
  `skill.def` 行，这是有意的——让你方能对普通攻击命中同样声明反馈绑定，而不必为此在内容里造一条
  假技能。内容校验不会因为这个 id 查不到对应行而报错。
- `event.skill_id` 条件过滤与 `from_display: skill` 经既有通用字段转发机制**自动生效**，
  你方不需要额外接线。

**ABI**：新增九参数构造函数重载，既有八参数重载原样保留。

## 升级影响

1. **无破坏性变更**。三条全是纯加法：`vfx.def` 新增可选字段（缺省行为与改动前逐字一致）、
   枚举新增一项、接口新增默认方法与重载。既有数据、既有实现、既有调用点都不需要改。
2. 若你方自行实现了 `IRenderer2D` 或 `IFeedbackSink`：**不需要改**。新成员都有默认实现；
   想要叠加混合 / 停止特效的实际效果时再按需覆写。
3. 新增的 `skill.native_auto_attack` 是框架保留 id，请不要在自己的 `skill.def` 里注册同名行。
