## 结论

三条阻塞一并解除，落在 **1.81.0**（标签 `v1.81.0`，发布提交 `1a469b16`，功能提交 `ac296171`）。ADR-0100（ADR-0072/0093 的对应"负面"条目已改为指向它）。数据格式与 `display.map`/`equip_visual` schema 不变，你方只需按下面的命名规则出图。

## 修法

- **反馈 1（装备层参与逐层剪辑）**：逐层探测的层集合改为"运行期实际合成出的层集合"（基础层 + 装备新增层 + 被装备覆盖的基础层），在挂接、方向槽位变化、**装备变化**（合成后层名集合变化）三个时机重探测；各层共享身体时间轴与取模读帧；脱下的层不再写帧，不在集合里的层一律不画。
- **反馈 2（按装备取帧集）**：装备提供的层候选顺序为
  `sprite_anim.<去前缀 mesh_ref>__<身体剪辑去前缀 ref>__<dir>__<layer>` → `sprite_anim.<mesh>__<身体剪辑 ref>__<layer>` → 回退静态层。
  去前缀规则同 `AssetRefConventions.StripCategoryPrefix`（去掉第一段类别、其余 `.`→`_`）。例：`mesh_ref = paperdoll.item.sample_sword`、身体走路剪辑 `sprite_anim.hero_walk`、层 `mainhand`、方向 `side_r` → `sprite_anim.item_sample_sword__hero_walk__side_r__mainhand`，落盘 `sprite_anim/item_sample_sword__hero_walk__side_r__mainhand/`。身体自有层候选仍是 ADR-0072 的两级公式。
- **反馈 3（覆盖剪辑走逐层+方向）**：武器风格 / 技能覆盖剪辑与默认状态剪辑走同一套探测：`<clip>__<dir>__<layer>` → `<clip>__<layer>`（装备层按反馈 2 规则，`<身体剪辑 ref>` 位置换成覆盖剪辑 ref）；逐层命中即隐藏 AnimRoot、驱动各层（不再分身）；未命中回退整身，整身也走 `<clip>__<dir>` 方向变体；播放中换向同样重探测。
- 冷加载：装备层/覆盖剪辑资源首次引用、加载完成后经 ADR-0099 的同一出口立即回填。
- 已知限制：覆盖剪辑的逐层候选链与整身方向变体链各自异步发起，可能对同一缺失资源各发一次加载确认（结果正确，不去重）。
