# 消费方反馈处理记录（样板游戏 A「俯视角动作 RPG」：任务目标指引缺口，2026-10-09）

> 本文档允许出现具体技术名（引擎/语言/框架/工具名），不受 `architecture/00～14` 与
> `architecture/adr/` 正文的禁用词约束。反馈来自样板仓库 `ws-game-samples` 里的"样板游戏 A"
> （`topdown_arpg`）的试玩：接了主线任务"终结枯骨之王"后，玩家找不到首领——屏幕提示一直停在
> "找卫队长接任务，然后走进拱门进入地牢"，不知道该清哪个房间、楼梯在哪、楼梯开没开。
> 按"上游缺口不绕行"规则，没有在游戏侧把"每个阶段指向哪里"硬编码进游戏代码，而是在框架分支
> `feature/quest-guide_20261009` 上补上通用能力。契约决定见 ADR-0173。

**结论先行**：缺口一项，已修并带红绿对照用例，纯加法（任务不声明 `guide` 时既有行为逐位不变，
`IQuestHost` 与既有构造签名均未改）：

| 编号 | 症状（消费方可观测） | 根因 | 修法 | 复现与不变量用例 |
|---|---|---|---|---|
| Q1 | 多地图、分阶段的任务没有任何"下一步去哪里"的信息：玩家看不到该去的房间/楼梯/首领的方向，楼梯是否开启也无从知道 | 08 第 2.3 节要求逻辑层暴露"当前激活目标的位置查询接口"，从未实现；任务只有目标进度，没有目标位置，游戏层只能硬编码 | `quest.def` 新增可选 `guide`（步骤：`map_id`/`when`/`text_key`/`targets[]`/`progress_flags[]`）与 `guide_priority`；新增 `QuestGuideHost.Evaluate(unitId, mapId, position)` 现算当前步骤、进度、箭头目标，目标在别的地图时沿当前开着的地图切换通道做广度优先搜索、箭头指向第一条通道；引擎适配层新增可复用的屏幕边缘箭头控件 `GuideArrow` | `QuestGuideHostTests` 13 条（阶段切换、进度与文案占位、可见条件与就近选择、跨地图寻路、通道关闭时步骤回落、多跳最短路径、优先级、地图限定、数据解析、坏形态校验、默认定位器）；`GuideArrowTests` 5 条 |

已知限制（逐字登记于 ADR-0173）：
1. 同地图内不做寻路，只给直线方向；墙体绕行由玩家自己判断。
2. 引导步骤的 `when` 只读任务与世界状态等既有 Expr 分组，不引入新分组。
3. 通道关闭条件只认 `area.trigger_def.condition`；由脚本或事件临时封路的通道不被识别。

## 怎么用

数据（`quest.def` 行里加 `guide`，目标写数据引用，不写坐标）：

```json
"guide_priority": 10,
"guide": [
  {"when": "quest.is_available(quest.main)", "text_key": "l10n.guide.talk",
   "targets": [{"spawn_ref": "spawn.npc_captain"}]},
  {"map_id": "world.town", "when": "quest.is_active(quest.main)", "text_key": "l10n.guide.enter",
   "targets": [{"area_ref": "area.town_to_dungeon"}]},
  {"map_id": "world.dungeon1", "when": "quest.is_active(quest.main) and not world.has(world.cleared_r3)",
   "text_key": "l10n.guide.clear",
   "targets": [{"area_ref": "area.enter_r1", "visible_if": "not world.has(world.cleared_r1)"}],
   "progress_flags": ["world.cleared_r1", "world.cleared_r2"]}
]
```

代码（缺省关闭：没有任何任务声明 `guide` 时 `HasAnyGuide` 为假、`Evaluate` 恒返回空）：

```csharp
var guide = gameplay.QuestGuide;                       // GameplayAssembly.QuestGuide
var info = guide.Evaluate(playerId, mapId, playerPosition);
if (info != null)
{
    hintLabel.text = info.FormatText(l10n.Get(info.TextKey));   // {done}/{total} 由进度代入
    if (info.Target != null) arrow.Present(worldCamera, ToWorld(info.Target.ArrowPosition), uiCamera);
    else arrow.Hide();
}
```

`GuideArrow.Create(parent)` 在全屏容器下建箭头；目标在屏内时箭头压在目标上方朝下，屏外时落在屏幕边缘朝向目标；
不调用就不会出现任何箭头。

## 非阻塞备忘

1. 同一次试玩还报了"上下走没有迈步动作"，根因是样板游戏 A 自己的正/背面走跑图集美术（腿几乎不动），数据与框架的剪辑/朝向选择正确；
   已在样板侧用本地 ComfyUI 重出，不涉及框架，仅在此登记以免被误认为框架缺陷。
2. 在工作树里跑含 Unity 的定向门禁时，"消费方演练"里的"registry 安装形态 additive 占位材质冒烟"会因工作树里没有
   `toolchain/registry/.npmrc`（被忽略的本机文件）而失败，与本次改动无关；主检出里该文件存在、该步骤通过。
